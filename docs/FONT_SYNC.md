# 字体同步检查与修复

检查日期：2026-10-09。范围：MizukiPanel 客户端界面、文章编辑与面板生成的预览。

## 字体规则

- 界面字体设置同时更新全局正文和等宽字体。选择系统字体时，源码、路径、日志等区域也使用系统等宽字体；选择面板字体时使用内置字体。
- 文章正文、大纲和编辑器内的界面文字采用正文字体设置。行内代码沿用正文，并保留反引号的专用字形补救。
- 文章代码块、分屏源码、新建正文/YAML/最终内容预览、模板生成预览、Frontmatter 值与修复源码、草稿比较采用文章代码字体设置。显式选择系统或面板代码字体保持独立；默认跟随项目时尊重界面的系统字体选择。
- 项目代码字体主要覆盖拉丁字符，中文回退到当前选定的正文字体，避免明确选择系统/面板正文后仍使用项目中文字体。

字体设置保存、预览、取消以及其他标签页的更新只改变字体来源。Vditor 实例、源码、光标与撤销历史沿用原有生命周期。

## 排查结果

| 区域 | 问题与处理 |
| --- | --- |
| 模板生成内容、新建正文和最终预览 | 原先固定使用面板等宽字体，已接入统一文章字体解析和设置预览 |
| 编辑器大纲、工具栏提示/面板 | 原先继承 Vditor 内置字体，已从编辑器根节点和大纲应用所选正文字体 |
| 代码块、分屏源码 | 原先项目字体及中文回退绕过部分设置，已统一解析显式选择、默认项目与全局系统字体的优先级 |
| Frontmatter 值、修复、草稿差异 | 已统一为文章代码字体，避免同一份源码在不同入口显示不同字体 |
| 配置 CodeMirror | 正文已使用全局变量，滚动容器和行号仍可能继承库自带字体；已补齐对应字体规则 |
| 特色页文本/JSON、相册和番剧编辑 | 使用全局等宽变量，变量现会随界面字体改变 |
| 配置/媒体路径、发布差异与路径、文章加载示意、运行日志 | 使用全局等宽变量，变量现会随界面字体改变 |
| 预览启动等待页 | 去除固定 Segoe UI，复制当前面板字体和显示样式、提供内置字体资源，并在等待期间同步字体切换 |
| 普通表单、导航、标题、仪表盘图表 | 使用 MUI 主题的正文变量，没有新增固定字体覆盖 |

实际 Mizuki 站点页面沿用站点配置的字体；图片、图标和数学公式使用对应资源或专用字形。字体检查不改写文章、站点配置或用户输入。

## 实现与验证

`src/client/font-families.ts` 定义统一字体栈；`editorFontFamilies` 解析文章正文/代码优先级；`useArticleFonts` 将同一解析结果应用到编辑器和文章源码显示。Vditor 通过根节点 CSS 变量原位更新，移除旧的项目字体覆盖规则。全局代码区域仍复用 `--mizuki-panel-font-mono`。

完整回归测试 43 个文件、169 项通过；补充字体优先级断言，验证全局系统选择、显式独立代码字体及中文回退。类型、格式和客户端/服务端生产构建通过。

隔离浏览器使用真实 Vditor、CodeMirror 和字体文件，API 使用临时模拟数据。核对系统/面板/项目字体、新建与模板预览、大纲、代码块、即时渲染/所见即所得/分屏、Frontmatter、全局代码编辑器、日志和等待页。浏览器实际字形查询确认代码块中的中文使用所选正文字体。字体切换保持编辑器节点和原生撤销，深浅色与移动端无新增横向溢出，没有文章写入或运行时异常。
