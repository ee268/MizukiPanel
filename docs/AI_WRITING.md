# AI 辅助写作

在“设置 → 文章编辑 → AI 辅助写作”选择 OpenAI 兼容接口或 Anthropic，填写 BaseURL、默认模型 ID、API Key、自定义系统提示词和最大输出 Token 数。“可切换模型”支持输入 ID 后按 Enter 添加，也可从上游列表选择；每家服务最多保存 100 个模型。两家服务分别记忆地址和模型，旧版单模型设置会保留，并作为可切换选项。

默认地址为 `https://api.openai.com/v1` 和 `https://api.anthropic.com`。支持服务根地址、带 `/v1` 的地址及完整对应接口地址；可使用 HTTPS 网关或本机 HTTP 服务，地址不能包含账号、密码、查询参数或片段。网关需要兼容所选服务的请求和响应格式。

## 使用

1. 打开文章，点击工具栏右侧“AI 写作”。面板为非模态，可拖动标题栏、加宽，或收起为悬浮按钮；编辑器仍可输入。再次点击悬浮按钮或工具栏按钮即可展开。
2. 已填写模型与本次会话密钥时，新会话自动请求 AI 阅读当前文章并概括主题、结构。未配置时先填写连接信息，再点击“读取当前文章”；直接发送要求也会先完成阅读。首次阅读与每次发送均读取最新正文，Frontmatter 不参与。
3. 输入问题点击“发送”进行多轮对话，也可按 Ctrl/Cmd + Enter 发送。点击“生成修改”会要求 AI 返回修改后的完整正文，可用于润色、续写、扩写或按自定义要求调整文章。
4. 修改结果显示“修改前 / 修改后”并标记增加、删除和变化的行。未变化的连续行折叠；变化过多时最多预览 600 行，完整建议仍可展开编辑。点击“采用正文修改”才进入文章草稿，可使用 Vditor 撤销，确认后手动保存正文。
5. 使用加号创建新会话，下拉框切换、删除按钮删除当前会话。每个会话独立保留记录、输入、连接与修改建议；连接区可随时切换服务或模型，后续请求继续携带当前会话历史。正文保存不会清空会话。

生成期间若正文发生变化，旧建议不能覆盖新草稿，需要重新生成。收起面板时请求继续进行，悬浮按钮显示处理标记；取消请求、删除会话或离开文章时，迟到响应不会写入对话或正文。只读工作区无法生成或采用建议。会话仅保存在当前文章页面内存中，切换文章、离开页面、刷新或退出后清空。

当前采用非流式请求，最多等待 90 秒；请求体上限 512 KiB，正文和单次返回最多 60000 字符，要求最多 4000 字符。历史发送最近最多 20 条、合计最多 60000 字符，界面仍保留完整会话。输出达到 Token 上限时提示内容可能不完整，并禁用正文采用，避免用截断结果替换全文。

## 获取模型列表

填写密钥后点击“从上游获取模型列表”，通过所选 BaseURL 查询模型，结果可搜索选择。支持 [OpenAI 模型列表](https://developers.openai.com/api/reference/resources/models/methods/list)与 [Anthropic 模型列表](https://platform.claude.com/docs/en/api/models/list)，后者跟随 `after_id` 分页，查询总时限 20 秒，最多 1000 个模型。查询不会自动覆盖默认模型和已保存列表；上游不支持模型列表时仍可手动添加 ID。是否支持文字对话取决于具体模型，上游返回的其他类型模型不保证能用于写作。

## 密钥与存储

- API Key 在独立的浏览器内存容器中按服务保存，不属于设置 schema。切换面板页面可继续使用；刷新、关闭页面、退出、登录失效或更换登录会话后清空。
- 密钥不写入 localStorage、IndexedDB、设置备份、偏好导出、退出恢复副本、项目文件或环境文件。输入框隐藏内容，不提供持久化密钥功能。
- 请求由已登录的本机面板服务转发，密钥只用于上游认证请求头。服务端不存储密钥，不记录请求体或上游错误正文；错误提示不回显密钥。禁止重定向，避免认证头随重定向发送。
- 写作请求或生成结果出现当前密钥、常见 OpenAI/Anthropic 密钥格式时拒绝发送或显示；采用前再次校验。
- 发布管理创建提交前检查实际暂存的文本内容和提交说明，发现常见密钥格式或 API Key 赋值则阻止提交并恢复此次暂存，保留工作区文件。此检查不修改既有提交历史，不覆盖用户在终端直接执行 Git 的行为，也不能保证识别所有自定义令牌格式。

模型、BaseURL 和提示词是可持久化的普通偏好，不应在其中填写密钥；设置字段也拒绝常见密钥格式。API Key 输入不触发设置草稿或保存动作。

## 模块与接口

- `src/shared/ai-writing.ts`：设置、任务、请求/结果契约和接口地址校验。
- `src/client/ai/`：内存凭证、连接控件、模型查询、独立会话、浮动面板、修改差异计算与展示。
- `src/client/settings/AiWritingSettingsForm.tsx`：保存普通写作偏好。
- `VditorBodyEditor`：捕获正文及光标、应用建议，保留 Frontmatter 与原生撤销历史。
- `POST /api/article/ai-writing`：登录、来源和工作区版本校验后的无持久化生成请求。独立于文件修改队列，不阻塞文章保存。
- `POST /api/ai/models`：登录、来源与工作区版本校验后的模型列表查询，不持久化查询凭证。
- `src/lib/server/ai-writing.ts`：写作与历史校验、对话/阅读/编辑模式适配。
- `ai-models.ts`、`ai-transport.ts`：模型分页、通用认证转发、取消/超时、响应大小限制及不回显上游错误。
- `src/lib/server/publish/credentials.ts`：仅检查暂存 blob，不把内容写入操作日志。

OpenAI 使用 [Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)，设置 `store: false`；Anthropic 使用 [Messages](https://platform.claude.com/docs/en/api/messages/create)，版本请求头为 `2023-06-01`。接口测试使用模拟响应，不消耗真实服务额度。
