# AI 辅助写作

在“设置 → 文章编辑 → AI 辅助写作”选择 OpenAI 兼容接口或 Anthropic，填写 BaseURL、服务支持的模型 ID、API Key、自定义系统提示词和最大输出 Token 数。两家服务分别记忆地址和模型，模型默认留空，避免假定服务可用的模型。

默认地址为 `https://api.openai.com/v1` 和 `https://api.anthropic.com`。支持服务根地址、带 `/v1` 的地址及完整对应接口地址；可使用 HTTPS 网关或本机 HTTP 服务，地址不能包含账号、密码、查询参数或片段。网关需要兼容所选服务的请求和响应格式。

## 使用

1. 打开文章，必要时先在正文中选中文字或放置光标，点击工具栏右侧“AI 写作”。
2. 选择续写、润色、扩写、缩写、提纲或自定义任务，填写补充要求。连接设置可临时调整，不改动已保存的偏好。
3. 点击“生成建议”。请求发送标题、要求、选中文字，以及勾选的正文上下文；Frontmatter 不参与生成。可以取消请求。
4. 建议可先编辑，再选择插入光标处、替换选中内容、替换正文或追加到正文。结果进入编辑器草稿，可使用 Vditor 撤销；确认后手动保存文章。

生成期间若正文发生变化，采用操作会拒绝覆盖，需重新打开写作窗口。切换文章或关闭窗口会取消未完成的请求；迟到的结果不会写入正文。只读工作区无法生成或采用建议。

当前采用非流式请求，最多等待 90 秒；请求体上限 256 KiB，正文上下文最多 60000 字符，选中文字最多 20000 字符，额外要求最多 4000 字符。超长文章可关闭正文上下文并处理选中片段。返回达到 Token 上限时提示内容可能不完整，不自动续写或发起额外请求。

## 密钥与存储

- API Key 在独立的浏览器内存容器中按服务保存，不属于设置 schema。切换面板页面可继续使用；刷新、关闭页面、退出、登录失效或更换登录会话后清空。
- 密钥不写入 localStorage、IndexedDB、设置备份、偏好导出、退出恢复副本、项目文件或环境文件。输入框隐藏内容，不提供持久化密钥功能。
- 请求由已登录的本机面板服务转发，密钥只用于上游认证请求头。服务端不存储密钥，不记录请求体或上游错误正文；错误提示不回显密钥。禁止重定向，避免认证头随重定向发送。
- 写作请求或生成结果出现当前密钥、常见 OpenAI/Anthropic 密钥格式时拒绝发送或显示；采用前再次校验。
- 发布管理创建提交前检查实际暂存的文本内容和提交说明，发现常见密钥格式或 API Key 赋值则阻止提交并恢复此次暂存，保留工作区文件。此检查不修改既有提交历史，不覆盖用户在终端直接执行 Git 的行为，也不能保证识别所有自定义令牌格式。

模型、BaseURL 和提示词是可持久化的普通偏好，不应在其中填写密钥；设置字段也拒绝常见密钥格式。API Key 输入不触发设置草稿或保存动作。

## 模块与接口

- `src/shared/ai-writing.ts`：设置、任务、请求/结果契约和接口地址校验。
- `src/client/ai/`：内存凭证、连接控件、生成状态和建议对话框。
- `src/client/settings/AiWritingSettingsForm.tsx`：保存普通写作偏好。
- `VditorBodyEditor`：捕获正文及光标、应用建议，保留 Frontmatter 与原生撤销历史。
- `POST /api/article/ai-writing`：登录、来源和工作区版本校验后的无持久化生成请求。独立于文件修改队列，不阻塞文章保存。
- `src/lib/server/ai-writing.ts`：输入校验、上游适配、取消/超时、响应大小限制及错误转换。
- `src/lib/server/publish/credentials.ts`：仅检查暂存 blob，不把内容写入操作日志。

OpenAI 使用 [Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)，设置 `store: false`；Anthropic 使用 [Messages](https://platform.claude.com/docs/en/api/messages/create)，版本请求头为 `2023-06-01`。接口测试使用模拟响应，不消耗真实服务额度。
