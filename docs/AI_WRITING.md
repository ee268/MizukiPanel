# AI 辅助写作

在“设置 → 文章编辑 → AI 辅助写作”点击 OpenAI 或 Anthropic 按钮选择服务，填写 BaseURL 及其下方的 API Key。每个“模型 ID”输入框填写一个模型，点击右侧加号新增输入框，减号删除输入框；点击框内的星标设为默认模型。空白行不保存，重复或无效 ID 需修正后保存；每家服务最多配置 100 个模型。两家服务分别记忆地址和模型，旧版单模型设置会保留。还可配置自定义系统提示词和最大输出 Token 数。

BaseURL 输入框默认留空，使用 placeholder 提示 `https://api.openai.com/v1` 或 `https://api.anthropic.com`；留空时请求使用对应官方地址。已保存的自定义地址仍显示在输入框中。支持服务根地址、带 `/v1` 的地址及完整对应接口地址；可使用 HTTPS 网关或本机 HTTP 服务，地址不能包含账号、密码、查询参数或片段。网关需要兼容所选服务的请求和响应格式。

## 使用

1. 打开文章，点击工具栏右侧“AI 写作”。面板为非模态，默认宽度 440px，可拖动标题栏移动，并从四边、四角拖拽调整尺寸；编辑器仍可输入。右上角关闭面板，再次点击工具栏按钮可重新打开。
2. 打开面板、恢复会话和新建会话不会请求 AI 或读取文章。阅读、分析或编辑请求才捕获最新正文及 Frontmatter 草稿，包括尚未保存的字段修改；普通聊天不携带文章。可要求“根据正文生成 tags 和 description”“把 draft 设为 false”“修改文章标题”，也可同时要求修改正文和字段。Frontmatter 页顶部也有“AI 写作”入口。密码、密钥、token、secret 字段不会发送给 AI，也不能由 AI 修改。
3. 输入问题点击“发送”进行多轮对话，也可按 Ctrl/Cmd + Enter 发送。消息以会话气泡显示：你的消息靠右，AI 回复靠左，短消息随内容收窄，长文字自动换行。AI 回复使用 Vditor 的只读 Markdown 渲染，支持标题、加粗、列表、引用、链接、表格、代码高亮和数学公式；文字可以选中复制，不出现编辑器或源码编辑状态。字体跟随面板偏好，适配深浅色和窄屏；长代码与表格在内部横向滚动。AI 自动判断本轮是讨论还是修改要求；润色、续写、扩写等修改要求也直接通过“发送”提交，无需单独点击生成按钮。
4. 仅在产生实际正文修改时，回复区域显示“修改前 / 修改后”及“采用正文修改”按钮，并标记增加、删除和变化的行；普通讨论或与原文相同的正文不会显示修改控件。未变化的连续行折叠；变化过多时最多预览 600 行，完整建议仍可展开编辑。点击“采用正文修改”才进入文章草稿，可使用 Vditor 撤销，确认后手动保存正文。
   Frontmatter 建议单独显示字段名、修改前和修改后的值。点击“采用 Frontmatter 修改”只更新字段草稿，正文保持原样，再到 Frontmatter 页手动保存。支持新增、修改和明确要求的字段删除，未知字段及原 YAML 注释保留。采用前校验 YAML、字段类型、必填标题和发布日期；当前字段已变化或输出截断时禁止采用。正文和 Frontmatter 分别检查是否过期，可独立采用；字段建议和采用状态也随会话保存。
5. 输入框下方左侧依次为新建会话、会话列表、删除当前会话。列表以弹出菜单显示，点击条目切换会话；条目右侧提供改名和删除按钮，名称支持 1–40 字。首次任务提交时由 AI 生成简短标题，手动改名不会被覆盖。每个会话独立保留记录、输入、模型与修改建议；发送按钮左侧的模型菜单可切换已配置的模型。正文保存不会清空会话。发送及收到回复后自动滚动到最新内容，可手动翻阅历史。

生成期间若正文发生变化，旧建议不能覆盖新草稿，需要重新生成。关闭面板后进行中的请求仍保留；取消请求、删除会话或离开文章时，迟到响应不会写入对话或正文。只读工作区无法生成或采用建议。会话自动保存到面板 `.local/ai-conversations/`，按项目路径与文章标识分隔；切换文章、刷新或重启后自动恢复该文章的全部会话及上次选中项。未完成的请求不会自动重发，恢复时保留原要求供再次发送。删除文章时，该文章全部会话、输入草稿、上次选中项和修改建议一并处理：永久删除时删除对应会话文件；移入回收站时将文章与会话保存为同一个回收项，恢复文章时同时恢复会话。回收项的体积包含会话文件，清理该回收项也会清理其中的会话；已有文章或会话不会被恢复操作覆盖。文章已删除时，迟到的会话保存请求不会重建会话文件。文章重命名会对应新的标识，旧会话文件仍保留。存储不包含 API Key，并受 `.gitignore` 保护；保存失败会显示提示，不覆盖原文件或其他页面的新版本。

明确阅读或 Frontmatter 编辑要求直接读取当前草稿，有歧义的要求由 AI 判断。阅读使用普通 Markdown，兼容旧 JSON 回复，且不提供正文或字段修改。首次明确任务另发一个不携带文章的简短命名请求，命名失败不阻止回答。编辑返回 `reply`、可选完整 `body` 和可选字段补丁 `frontmatter`；字段补丁为 `[{"key":"tags","value":"[Qt, AI]"}]`，value 是 YAML 字符串，null 表示删除。只改字段时禁止产生正文修改，只改正文时禁止产生字段修改；不完整或无效 JSON 不能用于改写文章。

当前采用非流式请求，最多等待 90 秒；请求体上限 1 MiB，正文及单次返回最多 60000 字符，Frontmatter 上下文最多 200 个字段、60000 字符，每次补丁最多 100 个字段，要求最多 4000 字符。历史发送最近最多 20 条、合计最多 60000 字符。输出达到 Token 上限时提示不完整，并禁止采用正文及字段建议。

## 获取模型列表

填写密钥后点击“从上游获取模型列表”，通过所选 BaseURL 查询模型，成功后自动将结果与已有模型合并、去重，逐项填入模型 ID 输入框，每家服务最多保留 100 个；保留已有默认模型，列表原先为空时使用首个结果作为默认模型。达到上限时需先删除不需要的模型。支持 [OpenAI 模型列表](https://developers.openai.com/api/reference/resources/models/methods/list)与 [Anthropic 模型列表](https://platform.claude.com/docs/en/api/models/list)，后者跟随 `after_id` 分页，查询总时限 20 秒，最多 1000 个模型。上游不支持模型列表时仍可手动添加 ID。是否支持文字对话取决于具体模型，上游返回的其他类型模型不保证能用于写作。

## 密钥与存储

- 输入 API Key 后点击“保存 AI 辅助写作”或设置页的统一保存按钮，会将 AI 配置与两家服务的密钥保存到面板 `.local/secure/ai-credentials.dpapi.json`（使用自定义状态目录时跟随该目录）。文件只含密文，原子替换时的临时文件也只含密文；不生成明文密钥文件或本地解密主密钥。首次读取且新文件不存在时，会验证并复制原 `%LOCALAPPDATA%/MizukiPanel/secure/` 下的加密文件，旧文件保留；已有新文件不会被旧文件覆盖。
- 使用 Windows [DPAPI CurrentUser](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.protecteddata?view=netframework-4.8) 加密，绑定保存时的 Windows 账户。重启面板后登录会恢复 AI 配置和“已加密保存”状态，浏览器不会取回原密钥；服务端仅在调用上游时解密使用。复制到其他账户不能直接使用。目前加密保存支持 Windows；其他系统拒绝持久化，仍可临时填写密钥使用。
- 非敏感的服务、地址、模型和提示词按普通偏好保存到 `.local/personal-settings.json`，同时在加密文件中保留副本。所有浏览器登录同一面板后共享配置。API Key 不属于偏好 schema，不写入 localStorage、IndexedDB、明文偏好备份、偏好导出、退出恢复副本或环境文件。未保存的密钥只在页面内存中，刷新、退出或登录失效后清空；已加密保存的密钥保留，重新登录后可用。
- 每次修改加密配置前自动备份原密文到 `.local/backups/settings/`；保存完成后也可点击“创建加密备份”。在“设置 → 备份与维护 → 备份管理”筛选“本机设置”，查找 `secure/ai-credentials.dpapi.json`，预览并恢复。恢复先验证当前账户可解密，备份不显示原密钥；恢复时也会同步 AI 普通偏好。备份仍绑定原 Windows 账户，不能作为跨账户密钥迁移文件。普通偏好导出只包含服务、模型等公开配置；需要备份密钥时保留加密备份和元数据文件。
- API Key 输入框不回填已存密钥。输入新值并保存会替换所选服务的密钥，另一家服务保持不变；点击框内清空按钮后保存会删除所选服务的当前密钥，历史加密备份仍按保留规则保存。取消修改会撤销未保存的密钥输入或删除操作。
- 请求由已登录的本机面板服务转发，密钥只用于上游认证请求头。安全存储接口要求登录，写入校验来源；返回配置和保存状态，不返回密钥，响应禁止缓存。保存使用版本校验，拒绝其他页面的过期覆盖。请求体、解密内容、密钥和上游错误正文不进入日志。禁止重定向，避免认证头随重定向发送。
- 写作请求或生成结果出现当前密钥、常见 OpenAI/Anthropic 密钥格式时拒绝发送或显示；采用前再次校验。
- 发布管理创建提交前检查实际暂存内容和提交说明，发现常见 API Key、私钥、当前已保存的自定义密钥（含其 Base64 形式）或加密密钥存储文件时阻止提交，并恢复此次暂存，保留工作区文件。加密文件仍不允许进入仓库，并有 `.gitignore` 防护。
- 推送前检查目标远程尚未接收的 Git 对象，包括历史提交说明和文件内容。即使敏感值曾在终端提交，面板也会拒绝推送包含这些敏感值的历史；敏感文件随后删除仍会被拦截。检查有时间、对象数量和总大小上限，无法完成或密钥存储损坏时停止 Git 操作。面板不能拦截用户直接在外部终端执行的提交或推送，也不保证识别任意未知、混淆或已不在存储中的自定义令牌。

模型、BaseURL 和提示词是普通偏好，不应在其中填写密钥；保存时也会拒绝将已存密钥放入这些字段。API Key 输入和清空会标记 AI 设置未保存，但原值始终与普通设置草稿分离，不进入草稿恢复、导出或普通备份。加密失败、文件损坏或换用其他 Windows 账户时显示错误，保留原加密文件，不降级为明文保存。

## 模块与接口

- `src/shared/ai-writing.ts`：设置、任务、请求/结果契约和接口地址校验。
- `src/client/ai/`：内存凭证、连接控件、模型查询、独立会话、浮动面板、修改差异计算与展示。
- `src/client/settings/AiWritingSettingsForm.tsx`：保存普通写作偏好。
- `VditorBodyEditor`：捕获正文及光标、应用建议，保留 Frontmatter 与原生撤销历史。
- `POST /api/article/ai-writing`：登录、来源和工作区版本校验后的无持久化生成请求。独立于文件修改队列，不阻塞文章保存。
- `POST /api/ai/models`：登录、来源与工作区版本校验后的模型列表查询，不持久化查询凭证。
- `GET /api/ai/conversations`、`PUT /api/ai/conversations`：按当前项目及文章读取、保存本机会话，写入校验版本、数据结构和敏感内容。单篇文章最多 100 个会话，每会话最多 500 条消息，合计最多 4 Mi 字符；超限时提示并保留原文件，可先删除不需要的会话。
- `GET /api/ai/credentials`、`PUT /api/ai/credentials`：读取本机 AI 配置及密钥保存状态，版本校验后加密保存；GET 不返回密钥。`POST /api/ai/credentials/backup` 创建密文备份。
- `src/lib/server/ai-vault.ts`：Windows DPAPI 加密、独立存储、版本冲突、密钥解密使用。
- `src/lib/server/ai-writing.ts`：写作与历史校验、对话/阅读/编辑模式适配。
- `ai-chat-result.ts`：区分对话说明与完整正文建议，仅返回有实际变化的正文，拒绝不完整的结构化回复。
- `ai-models.ts`、`ai-transport.ts`：模型分页、通用认证转发、取消/超时、响应大小限制及不回显上游错误。
- `src/lib/server/publish/credentials.ts`：仅检查暂存 blob，不把内容写入操作日志。

OpenAI 使用 [Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)，设置 `store: false`；Anthropic 使用 [Messages](https://platform.claude.com/docs/en/api/messages/create)，版本请求头为 `2023-06-01`。接口测试使用模拟响应，不消耗真实服务额度。
