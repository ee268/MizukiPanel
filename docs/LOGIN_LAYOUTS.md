# 登录页：晨光工作台

登录页布局固定为“晨光工作台”，入口为 `/login`。登录卡片仅保留“书页签笺”，旧的 `layout`、`card` 参数不会改变页面布局或样式。

## 登录卡片样式

书页签笺使用纸张折角、侧边主题色线、下划线输入和靠右按钮，移除样式切换入口及其他方案。深浅色、主题色和字体均跟随面板设置，不增加“本地访问”或锁图标。

## 布局与交互

- 页面高度跟随动态视口，一屏显示内容与页脚。桌面端左右排列；手机竖屏及较小的横屏隐藏创作区域和灵感便签，仅居中显示登录卡片。
- 登录卡片普通桌面最小高度为 390px，紧凑视口为 340px；低屏幕按可用高度缩小。标题、输入框和按钮均匀分布在可用空间中，减少集中在卡片上下的留白。
- 按宽度和可用高度压缩字号、卡片内边距与间距。紧凑视口保留英文引导、便签说明和卡片寄语，仅在高度不超过 440px 时收起这些装饰说明与创作标题，避免横屏操作区被挤出屏幕；移动端创作区域仍隐藏。
- 页面顶部不显示 logo。背景恢复原有的缓慢渐变流动和两层浮动光晕，入场过渡和便签动画适配深浅色，尊重系统减少动画偏好。
- 便签支持记录 / 分享 / 教程分类、切换提示、固定和最多 200 字输入。换提示保留手写内容。
- 创作标题、介绍和便签之间保留更充足的间距，便签内部的标题、分类、正文与操作区也适当拉开；低屏幕保留紧凑适配。
- 便签输入区最多显示两行，较长内容在输入区内滚动，避免撑高页面。卡片抽出距离随屏幕高度缩短，页面不因动画产生滚动条。
- “换个灵感”将底部卡片抽出并换到顶部，原顶部卡片退到底部；动画期间锁定便签操作，避免连续触发。减少动态效果模式直接切换；后台卡片不可聚焦，键盘焦点在交换后回到切换按钮。
- 便签内容仅在当前页面内保留，刷新或离开页面会重置，不写入项目或本地存储。
- 登录令牌默认隐藏，可切换显示；回车提交，验证期间禁用输入和按钮，防止重复提交。
- 后端认证、错误反馈和登录成功后进入工作区的流程保持现有实现。

## 模块职责

- `pages/LoginPage.tsx`：页面结构和响应式布局。
- `login/useLogin.ts`：令牌状态、验证请求和导航。
- `login/LoginForm.tsx`：登录表单与反馈。
- `login/card-styles.ts`：书页签笺的视觉样式。
- `login/LoginScene.tsx`：创作标题和便签布局。
- `login/NoteWidget.tsx`：便签交互。
- `login/content.ts`：便签提示内容。
- `login/login-styles.ts`：主题背景、入场动画和减少动态效果适配。
- `login/note-motion.ts`：卡片交换的运动路径与时长。
- `login/login-layout.ts`：紧凑、较低屏幕和横屏共用的响应式条件。

星轨、来信及其内容、动画和布局分支已移除。
