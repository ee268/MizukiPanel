## 本地草稿与恢复

草稿保存在浏览器 IndexedDB `mizuki-panel-drafts`，与个人设置分开。键包含真实项目根目录及实际内容根目录的哈希、文章路径和编辑会话 ID；同名文章、多标签页以及重新打开文章各自保留分支。切换独立内容仓库不会套用此前同路径文章的副本。

每条副本保留完整源文件、独立编辑的 Frontmatter 行、磁盘基准源码与版本、格式、时间和修订号。正文沿用现有源码保真路径，BOM、CRLF、未知字段和注释不会因保存副本而重新序列化。只有真实文章的未保存修改进入自动保存；教程、设置页试写预览和只读查看不生成新副本。

文章打开后提示可恢复分支，提供恢复到编辑区、查看差异、丢弃、暂不处理。差异视图并列展示基线、最新磁盘、本地草稿的完整源码与字段。恢复前再次检查副本修订和当前磁盘版本；磁盘已变更时必须先查看最新比较再明确恢复。当前已有未保存输入或读取过程中目标改变时停止恢复。恢复只填入编辑区，不写入磁盘、不自动合并，也不重建同一磁盘版本的 Vditor 实例。

文章页的“本地草稿列表”列出当前项目的分支，支持打开文章、比较、下载恢复 JSON 和明确丢弃单条副本。删除的文章保留副本并标记原文件不可用，仍可查看和下载，不自动重建文件。列表暂未包含某个路径时允许尝试打开，避免其他标签页重命名后使用过期列表误判删除。

### 保存、并发与失败

- 写入和删除使用 IndexedDB 事务及修订号比对，延迟任务带编辑代次，串行处理同一会话的操作。
- 手动保存前锁定编辑区并提交最新待保存副本。正文与 Frontmatter 分别保存时，另一部分仍未保存则保留恢复副本；全部保存后清除本会话及已恢复的原副本，其他会话分支保留。旧定时写入不会让已清除副本再次出现。
- 文章写入失败保留输入与副本。存储额度不足、数据库不可用、未来版本或无法识别记录提供提示；无法识别的原记录不删除。浏览器手动保存功能继续可用。
- 确认文件重命名成功后迁移可识别分支；确认删除成功后标记不可用。其他打开会话暂停旧路径自动写入，并尽力保留尚未落入副本的最新输入。
- 多标签页通过 BroadcastChannel 通知；不可用时仍可在页面获得焦点或手动刷新列表时重新读取。正常输入期间持续保存，导航和页面隐藏时尽力提交；浏览器强制终止时仍可能丢失最后尚未落盘的一段输入，不依赖卸载回调保证异步写入完成。

## 项目模板与创建校验

模板卡片使用项目设置的版本化保存、取消、恢复本组默认、外部修改提醒和离开保护。浏览器偏好与项目模板属于独立存储范围，“保存并离开”按范围顺序执行，部分成功时明确显示剩余失败范围。读取最新模板后可重新载入，旧输入不会被静默替换。

仅支持 `{{title}}`、`{{date}}`、`{{year}}`、`{{month}}`、`{{day}}`、`{{slug}}`，不执行表达式。YAML 先解析为映射，再替换字符串值，标题中的换行或 YAML 符号不会注入新字段。最终文件由原文章生成器构造，必填元数据覆盖默认字段，其他字段沿用现有校验。无效占位符、YAML、长度、扩展名和不安全路径在客户端与服务端拒绝。

新建对话框读取当前项目模板，可改标题、发布日期、草稿状态、路径、正文及默认字段；提供将创建的文件名、预览 URL 和完整文件内容。预览检查同名文件、URL 冲突和只读状态，不写入文件。创建绑定实际项目、设置版本及最终内容摘要，并再次检查；项目或设置变化、重名和旧预览均拒绝，表单输入保留，可更新预览基准后重试。已有文章不受模板更改影响。

新文章的 Frontmatter 使用逐行 YAML 键值格式，不继承 `{}` 的行内对象排版。预览与实际文件共用生成器，特殊标题、数组、嵌套字段和标量类型仍由 YAML 序列化处理；已有文章保持原有格式。

依据 Mizuki 的 `docs/CONTENT_AUTHORING.zh.md` 与 `src/content.config.ts`，文章必填字段仅为 `title` 和 `published`。默认模板显式包含这两个字段及安全占位符；创建表单提供实际标题和日期，`draft` 由草稿开关生成。其余字段可按需要添加，不添加旧版 `date` / `pubDate` 或由加载器生成的内部字段。
