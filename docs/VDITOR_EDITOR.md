# Vditor 文章编辑器

文章的“文档编辑”默认接入官方 [Vditor](https://github.com/Vanessa219/vditor) 4.0.0。通过 `pnpm` 拉取发行包并锁定版本，不修改上游源码；React 封装位于 `src/client/articles/VditorBodyEditor.tsx`。旧 Milkdown 编辑器、独立完整源码模式和备用入口已移除，正文统一使用 Vditor。

## 使用与保存

- Markdown 与内置教程默认使用即时渲染模式；Vditor 工具栏可切换所见即所得和分屏预览。
- MDX 文章默认使用分屏源码模式，以保留 import、JSX 和表达式。组件不会在面板中执行；Mizuki 自定义指令和 MDX 的最终效果仍通过真实预览核对。扩展内容通过 Vditor 原生正文模式编辑。
- Frontmatter 使用独立表单；解析失败时在 Frontmatter 页内编辑 YAML 并保存修复，正文保持原样。缺少完整头部时可添加新的 Frontmatter，原文作为正文保留。Vditor 仅编辑正文。`vditor-source.ts` 保留原始 Frontmatter 切片、BOM、注释和 LF/CRLF 换行约定。
- 打开、查看和无修改切换不会将 Vditor 初始化时的格式规范化结果写回草稿；撤销回初始正文时恢复初始原文。实际编辑会使用 Vditor 的 CommonMark/GFM 序列化，因此正文空白、标记写法可能被规范化。
- 保存按钮和 Ctrl+S 在调用现有保存流程之前同步读取当前编辑内容，避免输入回调的延迟造成漏存。切换 Frontmatter 前也会读取当前内容；切回正文沿用同一个 Vditor 实例，保留其撤销记录。
- 保存继续使用现有正文接口及片段校验；图片删除或语法结构改变无法满足片段校验时，沿用完整源码保存流程。版本冲突、只读模式和未保存 Frontmatter 的处理不变。

## 图片、样式与历史

图片工具接入现有媒体库和 URL/项目路径输入。Markdown 保存 `/images/...` 或文章相对路径，显示时通过 CSS 图片替换加载受限媒体 API，不把面板 API 地址写入正文。图片对话框保留插入位置，图片标签和含空格、括号的路径通过适配函数转义。

教程的 HTML 图片示例使用 `<div>` 区块包裹自闭合 `<img />`，避免 Lute 将带中文属性的独立图片标签识别为只显示源码的行内 HTML。代码示例与实际显示使用同一结构，保留中文替代文字、标题以及原生 HTML 区块编辑和撤销行为。

封装使用 Vditor 原生输入、撤销和重做，不在单次图片删除时重建正文编辑器。对即时渲染/所见即所得模式的选区删除，调用 Vditor 公开的 `deleteValue()`，避免上游首次按键记录光标时使 HTML 源码选区折叠。主题切换调用 `setTheme()`，保持正文和历史；只读和保存中调用 `disabled()`，自定义图片按钮同步禁用。

编辑区域适配面板深浅色主题以及系统/自定义字体；正文和代码字体分开。正文和 Frontmatter 共用文章页面，旧源码切换滚动逻辑已移除。

加粗文字和展开时的双星号标记使用正文同一中性色系的主文本色：浅色模式比正文更深，深色模式比正文更亮，不随主题强调色变化。代码块使用主题背景色和细边框，高亮代码的内部背景保持透明，避免浅色高亮主题的白色背景覆盖代码块底色；即时渲染、所见即所得、分屏预览及代码编辑状态沿用同一规则。

反引号包裹的行内代码跟随当前选择的正文字体，兼容系统与自定义字体模式；反引号本身仍使用符号补救字体以避免重叠。行内代码使用主题色文字和淡主题色背景：浅色模式加深文字，深色模式提亮文字并适当增加底色浓度，展开的反引号沿用文字颜色。链接文字及虚线下划线使用同一主题色，即时渲染模式中的链接节点和展开的原始语法也沿用此样式。主题色切换后同步更新；普通加粗文字保持中性色，代码块沿用原有语法高亮、独立代码字体和背景。

即时渲染模式单击链接即可在点击位置展开原始语法。封装在捕获阶段打开已有链接节点，让 Vditor 继续执行原生光标和标记处理，避免关闭打开链接功能后仍被上游的提前返回跳过编辑逻辑；不会重建正文或额外写入撤销记录。

格式工具栏滚动时固定在面板标题栏下方，“保存正文”位于功能栏右侧。全屏编辑区避开标题栏，支持通过原全屏按钮或 Esc 退出；进入时保留页面高度与阅读位置，退出、保存或离开页面时恢复页面滚动。编辑器使用固定类名的原生容器，避免主题更新覆盖 Vditor 的全屏和布局类。

左侧大纲滚动时固定在工具栏下方，高度限制在可见区域内，长大纲独立滚动。工具栏高度通过 `ResizeObserver` 测量，因此工具栏换行、窗口缩放和全屏切换后，大纲仍与工具栏底边对齐。

`vditor-strong.ts` 复用现有的宽松加粗边界处理，兼容 `QObject的**inherits()**函数` 等括号后紧接中文的写法。适配编辑器和分屏预览使用的 Lute 实例，也覆盖输入后的重新解析；临时字符只存在于同步解析过程，返回结果时还原，不进入可编辑 DOM、保存正文或撤销记录。链接地址、HTML 属性、代码和转义标记保留原有处理，不启用会改变 HTML 语义的整套 Protyle 解析模式。

全局“返回顶部”按钮供各页面共用，向下滚动后显示在右下角。普通模式返回页面顶部，文章全屏模式返回正文及预览滚动区域顶部；系统启用减少动画时直接跳转。

文章读取、编辑器组件和运行时初始化共用一个持续显示的 `ArticleLoading`。编辑器按最终页面宽度在隐藏区域初始化，就绪后一次性展示正文，不再出现第二段“编辑器加载”提示。初始化失败时结束加载并显示错误；Frontmatter 错误仍可直接修复。保存后的编辑器重建不重新显示整页加载，教程等待项目信息后沿用同一加载流程。

## 本地资源

`scripts/vditor-assets.ts` 为开发服务器提供 `/assets/vditor/` 资源，并在 Vite 生产构建时将发行包的 `dist/js`、`dist/css`、`dist/images` 和 MIT 许可证复制为同路径构建资产。Lute、中文语言包、图标、语法高亮、数学和图表依赖按 Vditor 的请求路径从面板同源加载，不依赖公共 CDN。升级依赖后重新构建即可同步资源。

`vditor-runtime.ts` 先完成语言包和 Lute 加载，再创建实例；错误显示在编辑区域内，支持 React StrictMode 与快速切换页面时的清理。网络图片和上游图表中使用远程服务的类型仍依赖各自地址。

## 验证

正文适配测试覆盖 Frontmatter/BOM/CRLF、MDX 原文和图片转义。隔离浏览器检查覆盖深浅色主题、三种编辑模式、正文及 Markdown/HTML 图片删除的撤销重做、立即保存、媒体库入口、Frontmatter 切换与错误修复、只读/保存状态与本地资源加载。运行 `pnpm check`、`pnpm test` 与 `pnpm build` 检查类型、回归和生产资源。
