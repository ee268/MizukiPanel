## 阶段 1：偏好基础与外观导航

**交付内容**

- 建立版本化设置模型、字段所属范围、统一默认值与客户端/服务端校验。
- 实现浏览器偏好，以及本机/项目设置的读取、分组保存、冲突检测和原子写入；项目设置按真实根目录隔离。
- 迁移旧主题，保留现有项目连接路径，处理缺失/损坏/更高版本配置。
- 接入设置页分组保存、取消、恢复默认、保存范围和未保存提示；支持分类地址。
- 完成主题模式、色相、界面字体/字号、侧栏偏好、返回顶部开关/阈值和操作提示时长；复用标题栏主题快捷入口。

**验收条件**

旧用户主题不丢失；无设置时与当前行为一致。保存/取消外观预览正确；多个标签页不会悄悄覆盖未保存表单。无项目仍可调整个人外观，保存失败不丢输入。深浅色、窄屏、键盘操作和两种导航宽度正常。

**阶段边界**

只建立后续领域需要的数据基础，不提前实现草稿、图片处理、维护或会话业务。基础 API 不执行文章、Git 或预览写入。

## 阶段 2：编辑器显示与行为偏好

**交付内容**

完成按格式自动/指定默认 Vditor 模式、大纲默认显示与宽度、正文字体来源/字号/行高、代码字体/字号/制表宽度和拼写检查。区分显示层即时设置与下次打开生效的构造参数，说明 MDX 能力边界。

**验收条件**

真实 Markdown、MDX、教程和 Frontmatter 场景正常。切换颜色、字体或大纲不重建编辑器，不改变 Markdown，不丢光标或撤销记录。链接、加粗、行内代码、代码块、HTML/Markdown 图片保留现有样式与编辑行为。保存与 Ctrl+S 同步读取最新正文。

## 阶段 3：草稿恢复与新文章模板

**交付内容**

- 增加本地草稿保存开关、延迟与状态反馈；按项目/文章/编辑会话保存完整正文及未保存 Frontmatter。
- 提供恢复、查看差异、丢弃与暂不处理；处理多标签页、磁盘更新、保存失败、重命名和删除。
- 实现项目级文章模板、默认字段与文件命名规则，预览创建结果并复用原文章校验。

**验收条件**

刷新后恢复此前未保存内容，包含独立修改的 Frontmatter。已有磁盘修改不会被恢复操作覆盖；保存后不会因延迟任务重新出现旧草稿。两个项目同名文章和两个编辑标签页相互隔离；存储失败有提示。临时教程不生成草稿，新模板不改动已有文章。

## 阶段 4：工作区与启动偏好

**交付内容**

实现恢复上次/默认项目/不自动连接的启动策略、最近项目管理、连接后页面选择，以及可额外开启的项目只读偏好。补齐旧连接状态迁移与项目标识重关联。

**验收条件**

无项目、失效路径和默认项目不可读时反馈准确，不连接错误项目。移除最近记录不删项目。切换项目处理未保存内容与运行中的预览；偏好不串项目。只读由服务端约束且不能解除检测引起的只读，也不阻止面板个人偏好保存。

## 阶段 5：媒体默认值与图片处理

**交付内容**

接入默认上传范围/目录、文件命名、图片引用和替代文字策略。新增可关闭的图片压缩、缩放和格式转换；评估处理依赖，明确支持格式、动画、透明度、失败回退与资源上限，展示上传前后的大小和目标文件名。

**验收条件**

默认关闭处理时维持现有上传行为。公共/文章相对资源在本地与独立仓库模式下路径正确；重名不静默覆盖。图片不放大，透明度与动画不误丢失，不支持格式可上传原文件。处理失败不写半成品；只读项目不可上传，Markdown 和 HTML 引用均正确显示。

## 阶段 6：预览与发布偏好

**交付内容**

实现项目预览端口/默认路径、外部服务连接说明、本机预览日志保留数量、浏览器日志字号/自动滚动和发布表单默认值。展示运行任务使用的配置与尚未应用的新值。

**验收条件**

端口冲突反馈准确，不自动终止外部进程；端口保存不重启当前任务，下次启动使用新值。默认路径不覆盖文章真实预览 URL；关闭自动滚动后可阅读旧日志。发布表单默认值不勾选提交文件、不执行任何发布动作，不改变运行中的任务。

## 阶段 7：备份维护与偏好迁移

**交付内容**

- 新保存/回收项建立稳定元数据；兼容已有缺少索引的备份，展示可确认的归属与恢复条件。
- 统一列表、占用、恢复、保留天数/数量设置及手动清理预览/执行；首版默认不自动清理。
- 实现按范围偏好导出、导入差异和结果、分组/批量恢复默认。

**验收条件**

旧备份不会被猜测归属或错误恢复。恢复检查当前版本，清理展示具体对象且旧预览失效时停止。最新恢复点和运行任务不受清理影响。导出排除令牌、Cookie、正文和草稿；导入不自动连接项目或发布，失败范围明确可见。恢复默认不清空用户内容或草稿。

## 阶段 8：会话策略与整体验收

**交付内容**

完成闲置退出与会话最大有效期，扩展服务端会话 ID 和有效期校验；区分用户活动与后台轮询。验证超时、手动退出、多标签页和本地草稿恢复。完成八阶段联调、迁移/失败用例、使用说明与当前实现文档更新。

**验收条件**

过期请求由服务端拒绝，后台日志与状态轮询不延长闲置时长。默认关闭超时策略时保留现有登录体验；超时后本地草稿仍可恢复，运行任务不被前端退出误停止。桌面/移动端、深浅色、无项目/只读、本地/独立仓库、多项目/标签页、存储失败及设置版本冲突全部完成回归。

## 阶段完成与回退记录

每阶段完成时更新本表状态，并记录涉及模块、迁移、已验证场景、限制及提交。涉及运行代码的阶段执行 `pnpm check`、受影响测试和 `pnpm build`；新增设置/存储/策略必须覆盖真实边界，不用只比较实现字符串的测试替代行为验证。

设置数据升级留有迁移副本；不兼容的降级只读处理，不删除新数据以换取启动。回退界面或功能实现时保留文章、草稿、偏好和备份，仍可沿用默认行为。文档阶段仅检查设计一致性、格式、链接和 Git 差异，不启动业务开发或修改用户连接配置。
