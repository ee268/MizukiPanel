## 阶段 1：偏好基础与外观导航

**交付内容**

- 建立版本化设置模型、字段所属范围、统一默认值与客户端/服务端校验。
- 实现浏览器偏好，以及本机/项目设置的读取、分组保存、冲突检测和原子写入；项目设置按真实根目录隔离。
- 迁移旧主题，保留现有项目连接路径，处理缺失/损坏/更高版本配置。
- 接入设置页分组保存、取消、恢复默认、保存范围和未保存提示；支持分类地址。
- 完成主题模式、色相、界面字体/字号、侧栏偏好、返回顶部开关/阈值和操作提示时长；复用标题栏主题快捷入口。

**验收条件**

旧用户主题不丢失；无设置时与当前行为一致。保存/取消外观预览正确；多个标签页不会悄悄覆盖未保存表单。无项目仍可调整个人外观，保存失败不丢输入。深浅色、窄屏、键盘操作和两种导航宽度正常。

**阶段边界**

只建立后续领域需要的数据基础，不提前实现草稿、图片处理、维护或会话业务。基础 API 不执行文章、Git 或预览写入。

**完成记录（2026-10-09）**

已交付三个浏览器设置分组（外观、导航、操作提示）、旧主题迁移和原始数据备份、分组保存/取消/默认值预览、分类地址与离开确认、多标签页同步/冲突提示、浏览器数据损坏后的备份恢复，以及本机/项目设置的版本化存储和受保护 API。标题栏主题快捷入口复用控件；侧栏可记忆状态，返回顶部开关/阈值及操作提示时长已接入全局使用。

本机 `workspace` 和项目 `media` 分组目前只建立数据契约与读写基础，其业务行为和表单分别在阶段 4、5 接入。其余五类继续显示空状态。浏览器使用 Web Locks 串行保存并比较被修改分组的基准值；缺少该能力的环境使用保存前比对。服务端复用文件锁、版本哈希、备份和原子替换；旧工作区路径保持原样。

验证记录包括迁移失败、存储额度不足、禁用存储、未来版本只读、损坏数据恢复、跨项目/跨标签页隔离、并发和旧版本保存、目录写入失败、深浅色、系统主题、字体预览、移动端与侧栏状态恢复。对应实现说明见 [阶段 1 说明](PANEL_SETTINGS_STAGE_1.md)。

## 阶段 3：草稿恢复与新文章模板

**交付内容**

- 增加本地草稿保存开关、延迟与状态反馈；按项目/文章/编辑会话保存完整正文及未保存 Frontmatter。
- 提供恢复、查看差异、丢弃与暂不处理；处理多标签页、磁盘更新、保存失败、重命名和删除。
- 实现项目级文章模板、默认字段与文件命名规则，预览创建结果并复用原文章校验。

**验收条件**

刷新后恢复此前未保存内容，包含独立修改的 Frontmatter。已有磁盘修改不会被恢复操作覆盖；保存后不会因延迟任务重新出现旧草稿。两个项目同名文章和两个编辑标签页相互隔离；存储失败有提示。临时教程不生成草稿，新模板不改动已有文章。

**完成记录（2026-10-09）**

已交付浏览器本地草稿开关、1—10 秒延迟与状态，IndexedDB 按真实项目/内容根目录、文章和编辑会话隔离完整源码及独立 Frontmatter。提供恢复、最新磁盘比较、暂不处理、单条丢弃、项目副本列表和下载；保存/部分保存、旧延迟任务、多标签页、磁盘更新、存储失败、重命名及删除均有保护。

项目模板提供正文、默认 YAML 字段、固定占位符命名规则和最终文件预览。创建绑定项目、设置版本与预览摘要，继续执行既有文章元数据、文件/URL 冲突和只读校验，失败保留输入。浏览器与项目设置共享离开提醒且明确部分保存结果。详见 [阶段 3 说明](PANEL_SETTINGS_STAGE_3.md)。

**完成记录（2026-10-10）**

**完成记录（2026-10-10）**
