# 项目结构整理

本次整理保持 API 路径、返回字段、文件格式与页面交互兼容，重点减少重复实现并拆分混合职责。

## 服务端职责

| 模块 | 职责 |
| --- | --- |
| `features/registry.ts` | 特色页与资源的静态描述、按名称查找 |
| `features/catalog.ts` | 页面列表、可用资源检测、站点配置中的页面开关 |
| `features/data.ts` | TypeScript 数据文件读取、校验后保存 |
| `features/text.ts` | Markdown 正文读取与保存 |
| `features/anime-seasons.ts` | 季度文件列表、作者默认值、读写与删除 |
| `features/albums.ts` | 相册信息和图片列表、相册校验与读写 |
| `features/paths.ts` | 内容模式对应的路径及写入许可 |
| `features/storage.ts` | 可选文件读取、备份目录和带快照校验的回收 |
| `features/validation.ts` | 数据表达式、URL、日期和重复 ID 校验 |
| `features/restore.ts` | 按资源类型恢复备份 |
| `publish/git.ts` | Git 执行、状态解析、根目录校验、差异限额 |
| `publish/runtime.ts` | 项目任务状态、互斥、日志脱敏与保留、输出流 |
| `publish/overview.ts` | 当前分支、上游、远程仓库与操作可用性 |
| `publish/history.ts` | 固定提交快照的查询、分页与历史差异 |
| `publish/changes.ts` | 所选文件校验、工作区差异、暂存/提交及失败清理 |
| `publish/push.ts` | 推送确认校验和当前上游推送 |
| `publish/build.ts` | 构建可用性和构建进程 |
| `workspace-history.ts` | 最近项目记录的读取和格式校验 |

两个领域入口只导出公共服务。运行任务仍共享原有的进程内状态、项目归属和互斥机制，拆分不会为每个模块创建独立任务锁。根目录限制、只读保护、版本冲突、备份和回收校验继续生效。

## 客户端职责

设置页面保留路由、分类导航、滚动归位和反馈布局。`useSettingsController` 汇总浏览器、本机和项目的设置快照、草稿与恢复内容；`useSettingsLeave` 负责未保存修改的离页/退出保护；`SettingsSections` 负责表单组合与懒加载。已访问分类保持挂载，未访问模块仍按原有视口策略加载。

`CatalogLayout` 统一配置和特色页的搜索容器、卡片网格及空结果提示。`catalog-styles` 统一卡片悬浮及减少动画策略。各自的卡片仍负责领域图标、路由和开关，目录组件继续通过 `CatalogCardSlot` 按视口挂载与卸载。

`ScopedCard` 独立提供本机与项目设置的保存、取消、默认值和冲突提示。媒体、会话、任务及维护表单直接使用它，不再导入工作区表单及其连接管理逻辑。

## 共享契约与依赖

项目报告、文章列表和 Frontmatter 条目、配置值与描述、特色页数据描述、字体模式统一定义在 `src/shared/`。原类型入口保留导出，避免一次整理要求所有调用方修改路径。客户端不导入服务端类型；共享层不依赖浏览器界面或服务端文件系统。

设置存储对工作区会话的反向依赖已改为直接读取最近项目记录，解除由它引起的设置、预览和发布服务循环依赖。结构测试持续检查跨层导入及运行时循环。

## 清理与验证

已删除旧版 `src/routes` 及其 6 个空子目录。仅删除确认没有任何文件的目录；构建产物、依赖、运行状态、项目内容和已有未提交改动不参与目录清理。

验证包括 TypeScript 检查、全量测试、客户端与服务端生产构建，以及设置分类、离页保护、目录搜索/卡片和深浅色的浏览器冒烟检查。

全量 360 项测试通过；浏览器检查确认分类间草稿保留、滚动归位、离页取消/放弃/保存、退出保护、卡片按视口加载、搜索与空结果、特色页开关、深浅色和窄屏布局。浏览器使用临时测试数据，Git、存储和接口行为由隔离目录的服务端回归测试验证。
