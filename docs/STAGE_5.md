# 阶段 5：站点配置

阶段 5 已完成 Mizuki 18 个可覆盖配置的本地管理与独立内容仓库覆盖管理。

## 交付内容

- 配置目录采用顶部搜索和分类卡片网格，按站点外观、导航布局、互动内容、链接渲染和特效用分隔线分组。卡片包含图标、名称、英文名称；支持中文、英文、分类与文件名搜索。
- 卡片仅在进入视口时挂载，离屏后卸载内容，以固定高度占位保持滚动位置；滚动进入时播放过渡动画，悬浮时轻微抬升和强调图标。减少动态效果偏好下关闭动画。详情代码编辑器和配置数据也只在打开详情后加载。
- 详情统一采用配置编辑／配置备份分区标签，切换标签保留正文、编辑器撤销历史和当前备份选择；保存栏按正常布局排列，避免页面滚动时遮挡代码。返回目录保留搜索和滚动位置，未保存编辑离开前提供保存、放弃和继续编辑选择。详情链接沿用 `/config?key=<配置名>`。
- 本地模式修改 `src/config/*.ts` 中对应的导出对象；独立仓库模式修改 `<CONTENT_DIR>/overrides/<导出名>.ts`。
- 配置编辑页显示当前可编辑源码；移除了默认/覆盖/最终值比较页签、来源标签和差异数量标识，服务端仍保留深合并规则。
- 使用 TypeScript Compiler AST 定位导出对象，只替换对象初始化表达式，保留文件的导入、类型注解和外围注释。
- 写入前拒绝函数调用、数组展开、计算属性等可执行或不确定表达式；枚举与已声明标识符只做静态展示，不执行配置源码。
- 每次首次修改前保留一份完整文件备份，同一次编辑的连续输入不重复创建。保存、放弃或全部撤销后重新编辑会创建新备份；保存前等待备份完成，失败可重试且保留输入。
- 按项目、内容根目录和配置名分别保留最近 5 份，超出时原子替换最旧的一份。配置页提供备份选择和恢复入口；恢复前备份当前内容，存在未保存编辑时先保存或放弃，再恢复。
- 独立仓库首次创建覆盖文件前也会记录其不存在状态，恢复该状态会删除新增覆盖文件；版本冲突、只读项目或备份校验失败会阻止写入。
- 独立仓库的新覆盖文件支持 `LinkPreset` 自动导入，空对象可用于恢复默认行为。

## 合并语义

- 普通对象递归合并。
- 数组、标量和 `null` 整体替换。
- 显式 `undefined` 跳过，保留默认值。
- 覆盖机制无法表达删除；面板不会把清空字段伪装为删除。
