# 阶段 5：站点配置

阶段 5 已完成 Mizuki 18 个可覆盖配置的本地管理与独立内容仓库覆盖管理。

## 交付内容

- 左侧按站点外观、导航布局、互动内容、链接渲染和特效分组展示配置。
- 本地模式修改 `src/config/*.ts` 中对应的导出对象；独立仓库模式修改 `<CONTENT_DIR>/overrides/<导出名>.ts`。
- 同时展示上游默认值、内容仓库覆盖值和深合并后的最终值，并列出差异路径。
- 使用 TypeScript Compiler AST 定位导出对象，只替换对象初始化表达式，保留文件的导入、类型注解和外围注释。
- 写入前拒绝函数调用、数组展开、计算属性等可执行或不确定表达式；枚举与已声明标识符只做静态展示，不执行配置源码。
- 复用原子写入、版本冲突检测和备份机制；已有文件保存后可立即恢复。
- 独立仓库的新覆盖文件支持 `LinkPreset` 自动导入，空对象可用于恢复默认行为。

## 合并语义

- 普通对象递归合并。
- 数组、标量和 `null` 整体替换。
- 显式 `undefined` 跳过，保留默认值。
- 覆盖机制无法表达删除；面板不会把清空字段伪装为删除。

## 验证

- 面板 `pnpm check`、`pnpm test`、`pnpm build`。
- 真实 Mizuki 的 18 个配置逐一完成只读 AST 解析。
- 测试夹具覆盖本地保存与恢复、独立仓库首次创建覆盖文件、深合并、冲突版本和危险表达式拒绝。
- Mizuki `pnpm check`、`pnpm type-check`、`pnpm build`。

Mizuki 构建中已有文章代码块语言回退警告仍会显示，但没有诊断错误，构建成功。
