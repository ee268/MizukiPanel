# 站点配置布局

配置目录使用顶部搜索框、五组分类分隔线和响应式卡片网格。每个卡片只展示图标、中文名称与英文配置名，点击后进入独立详情视图。默认目录不读取任何配置正文或备份，不加载 CodeMirror；按需加载卡片组件和详情编辑器。

## 卡片与搜索

- 搜索范围：中文名称、英文配置名、分类和源文件名，多个空格分隔的词同时匹配；搜索保存在 URL 的 `q` 参数中。
- 输入时提供最多六条联想建议，展示中文名称、英文配置名和分类；鼠标选择或方向键与回车确认后填入名称并筛选卡片，Escape 关闭建议。中文输入法组词期间隐藏建议，选词完成后再更新搜索。
- 窄屏单列，宽屏按至少 220px 的列宽自动排布，使用 144px 的固定卡片高度作为占位；不可见卡片不挂载正文，焦点中的卡片保留到焦点离开，保障键盘操作。
- 滚动入场采用淡入和向上位移，悬浮采用轻微抬升、边框与图标变化。尊重系统减少动态效果设置；首次进入页面与后续滚动分别处理，避免叠加动画。

## 详情版本

| 版本 | 布局 | 适用场景 |
| --- | --- | --- |
| 专注编辑（默认） | 居中宽幅编辑，备份位于下方，保存操作栏随滚动固定。 | 阅读和修改较长配置。 |
| 双栏工作台 | 宽屏下编辑器与备份并排，备份固定在旁；窄屏自动纵向排列。 | 频繁查看和恢复备份。 |
| 分区标签 | 编辑与备份分区切换，共享固定操作栏。 | 希望减少同时显示的内容。 |

详情页顶部可随时切换三个版本，代码编辑器不卸载，保留正在输入的内容和撤销历史。浏览器记住上次选中的布局。现有只读限制、编辑前自动备份、最近五份独立备份、版本冲突校验、恢复与清空覆盖均继续生效。

返回目录保留搜索与滚动位置；未保存修改通过路由阻止器处理，可保存后离开、放弃修改或继续编辑。浏览器返回、配置深链接和站点配置的其他导航入口共用相同逻辑。
