# 设置阶段 1：偏好基础与外观导航

完成日期：2026-10-09。

## 已接入功能

- 外观：浅色/深色/跟随系统、主题色相、内置/系统界面字体、12—20px 基准字号。系统字体同时应用到编辑器正文和行内代码，预览取消后恢复项目字体；代码块保留独立等宽字体，不重建编辑器。
- 导航：下次加载默认折叠/展开/记住上次状态、全局返回顶部按钮开关与 100—1000px 显示阈值。
- 操作提示：2000—10000ms 的成功/信息提示时长，用于文章、媒体、配置、特色页与设置保存提示；错误保留显式反馈。
- 每组独立保存、取消、恢复本组默认。外观和返回顶部支持预览；恢复默认先填入草稿，不立即落盘。
- 分类地址为 `/settings?section=appearance` 等，未知分类回退至外观。离开有未保存设置的页面时可保存、放弃或继续编辑；浏览器刷新/关闭使用原生未保存提示。
- 标题栏主题入口保留即时保存模式，复用主题控件。正在编辑的同组被快捷入口或其他标签页修改时保留草稿、取消旧预览并要求重新载入。

## 数据与迁移

浏览器个人偏好使用 `mizuki-panel-preferences`，包含 schema 版本、修订 ID、时间和分组值。原 `mizuki-panel-theme` 成功迁移并确认后才删除，原始主题备份仍保留；失败时临时使用原主题。无配置的读取不创建新设置文件。

个人设置按字段校验，非法字段回退默认并提示；未知扩展数据保留。数据无法解析时暂停写入，提供确认后的恢复默认并先备份原数据；更高 schema 版本只读，不提供降级重置。浏览器存储被禁用或额度不足时保留表单输入与可用预览，明确提示未保存。

同源标签页通过 `storage` 事件同步。保存使用 Web Locks（支持时）串行执行，在锁内重新读取并对比所修改分组的基准值，然后一次写入所有待保存分组；不同组可合并保存。未支持 Web Locks 的环境使用保存前比对，不能提供跨标签页锁的同等保证。侧栏的记忆状态沿用导航分组；同组未保存导航修改时若状态被更新，也会触发外部修改提醒。

本机文件为 `.local/settings.json`，项目文件为 `.local/project-settings/<projectKey>.json`。项目标识按真实根目录生成，项目文件不写入 Mizuki 或独立内容仓库。API 保存携带文件版本哈希，内部复用文件锁、备份和原子替换；JSON 中的修订 ID 用于记录状态，文件哈希另用于检测外部编辑。schema 0 在首次保存时保留旧文件备份；损坏/未来版本状态不自动覆盖。

`GET /api/settings` 返回本机和已连接项目的设置状态；`PATCH /api/settings` 校验范围、分组、字段、版本和当前项目标识。无项目时仍可调整浏览器偏好，只读项目仍可保存面板偏好。工作区原 `.local/workspace.json` 保持兼容，尚未接入新的启动策略。

已登记的本机 `workspace` 与项目 `media` 分组用于后续功能的存储基础，目前没有表单或业务应用。默认启动项目、媒体默认目录等按阶段 4、5 实施；此次未开展草稿、模板、图片处理、备份清理或会话功能。

## 模块

| 模块 | 职责 |
| --- | --- |
| `src/shared/panel-settings/` | 字段所属范围、类型、默认值、校验与封套解析 |
| `src/client/settings/personal-storage.ts` | 浏览器存储、主题迁移、分组比对与损坏恢复 |
| `PersonalSettingsProvider.tsx` / `usePersonalDrafts.ts` | 已保存状态、预览、同步、草稿与保存反馈 |
| `ThemeControls.tsx` / `AppearanceSettingsForms.tsx` | 共享主题控件与三个实际表单 |
| `src/lib/server/panel-settings.ts` | 本机/项目文件存储与身份、版本检查 |
| `src/server/routes/settings.ts` | 受保护的读取与分组保存 API |

入口使用 React Router 数据路由承载既有 `App` 路由，使设置页可通过原生 blocker 处理分类切换、导航及前进/后退。外观更新通过主题 Context/CSS 变量，侧栏策略在下次加载生效；代码字体、文章编辑模式和 Vditor 实例不由该阶段重建。
