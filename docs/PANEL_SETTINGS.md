# MizukiPanel 设置

设置入口固定在导航栏底部、关于入口上方，路径为 `/settings`，沿用登录校验。折叠侧栏显示齿轮图标和悬停提示；展开侧栏和移动端抽屉显示“设置”文字。页面具备响应式分类导航与内容区域，暂未新增设置控件或修改现有功能的保存行为。

分类定义位于 `src/client/settings/sections.tsx`，页面位于 `src/client/pages/SettingsPage.tsx`。桌面使用纵向分类，窄屏使用可横向滚动的分类标签；各分类提供独立的可访问内容面板，后续可接入各自的设置表单。

## 建议设置项

以下为对当前实现的梳理和后续建议，未实现的选项不出现在页面中。

| 分类 | 可提供的设置项 | 当前情况与建议 |
| --- | --- | --- |
| 外观与导航 | 深浅色/跟随系统、主题色相、界面字体与字号、侧栏展开偏好、返回顶部按钮开关 | 主题模式和色相已在标题栏提供，并保存在当前浏览器。其余偏好暂不可配置；侧栏每次挂载默认折叠，返回顶部固定在滚动超过 240px 后显示。优先整合已有主题控件并记住侧栏状态。 |
| 文章编辑 | 默认 Vditor 模式、大纲开关与宽度、正文字体来源、字号/行高、代码字体和制表宽度、拼写检查 | Markdown 默认即时渲染，MDX 默认分屏；字体来源跟随项目站点配置。建议提供面板自己的编辑偏好，并保留按文件格式选择默认模式的能力。 |
| 文章编辑 | 本地草稿保存与恢复、保存提醒、新文章模板、默认 Frontmatter 字段、文件命名规则 | 当前文章手动保存，离开未保存文章会提示。建议优先提供草稿恢复；模板与命名偏好按项目保存，避免不同博客互相影响。 |
| 工作区 | 最近项目、启动时恢复上次项目的开关、默认项目、连接后行为、只读偏好 | 已能连接/切换本地项目，保存并读取上次项目路径。可以补充最近项目和启动行为的选择；目录访问校验、版本冲突保护继续强制执行。 |
| 媒体管理 | 默认上传范围、目录规则、文件命名、插入时的相对/公共路径偏好、默认替代文字 | 当前默认公共资源，上传范围与目录在上传表单选择。建议先记住范围和目录，再提供命名与引用规则。图片压缩、尺寸限制和格式转换属于需要另行开发的能力。 |
| 预览与发布 | Astro 预览端口、默认预览路径、连接外部预览服务的方式、日志保留条数/自动滚动、发布操作默认选项 | 当前预览端口固定为 4321，最多保留 300 行运行日志。建议提供端口、日志与预览路径偏好；Git 上游变更和真实推送仍须明确操作。 |
| 备份与维护 | 备份/回收内容列表、保留天数与数量、存储占用、按范围清理、导出/导入个人偏好、恢复默认 | 现有保存备份和删除回收机制，但缺少统一查看与保留策略。优先提供备份查询、恢复和占用展示，再提供明确范围的清理。 |
| 备份与维护 | 闲置自动退出、会话有效期、操作提示的显示时长 | 当前使用启动访问令牌登录，支持手动退出，提示时长由各页面固定。后续可提供会话与提示偏好；会话有效期需要同时落实服务端校验。 |

## 保存范围与优先级

浏览器个人偏好适合保存主题、导航状态、编辑器显示和日志显示习惯；项目偏好适合保存文章模板、媒体路径规则和预览参数。访问令牌、服务监听地址等运行参数沿用启动配置，不能作为普通偏好随导出文件分发。Mizuki 博客的主题、个人资料、页面导航等仍通过“站点配置”管理。

建议先完成外观与导航、编辑器偏好和本地草稿恢复，再补充媒体/预览默认值以及备份管理。各分类实现后显示真实可操作的控件；设置应说明生效范围，支持恢复默认，需要重启的项应明确提示。
