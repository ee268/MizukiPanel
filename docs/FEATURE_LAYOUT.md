# 特色页面目录

特色页面使用搜索栏和紧凑卡片网格，支持按中文名称、英文名称和页面路径搜索。联想建议、中文输入法处理、按需挂载、滚动入场和减少动态效果适配与站点配置目录共用组件。进入目录只读取清单，打开页面时才加载正文或数据编辑器。

卡片右上角的开关独立于编辑入口，修改后立即保存。服务端只修改 `siteConfig.featurePages` 对应布尔字段，保留其他配置源码、注释和标识符；外部内容模式写入 `overrides/siteConfig.ts`，不改默认源码。保存前创建站点核心配置备份，沿用最近五份、版本冲突和只读校验。冲突时刷新开关状态，失败时回退显示，保存期间暂时禁用其他开关，避免同一配置版本重复提交。

关于页在 Mizuki 中没有定义 `featurePages` 开关，显示不可操作的常开开关。常开开关采用柔和的主题色按钮与轨道，适配深浅色，并通过提示说明不可关闭。其他九个页面可以启用或关闭；关闭页面仍能编辑内容，导航配置需要单独管理。

目录路由为 `/features`，点击卡片进入 `/features/<页面英文名>`，例如 `/features/friends`、`/features/anime`、`/features/aiTools`。支持复制链接、新标签页打开、直接访问、刷新及浏览器前进／后退；未知页面提示返回目录，不加载数据。详情中侧边导航继续高亮特色页面入口。

打开过的页面在返回目录或切换其他卡片时保留编辑器实例、草稿和撤销记录，并继续参与退出登录时的修改恢复机制。返回目录保留搜索词和滚动位置；从目录进入时返回上一条历史记录，直接打开详情时返回目录。页面路由切换的过渡只应用到标题，编辑器保持稳定。

追番使用季度文件时，列表用主题色背景、加粗文字和左侧色条标记当前选中条目；读取失败回退到原选中项。切换文件后，右侧详情淡入并轻微横移；系统开启减少动态效果时不播放动画，点击编辑区域也会立即结束动画。重复点击当前文件不重新读取，保存当前文件不重建编辑器或清空撤销记录。
