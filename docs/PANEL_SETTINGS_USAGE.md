# MizukiPanel 设置使用说明

设置八阶段已完成。点击侧栏底部、关于入口上方的齿轮进入 `/settings`；窄屏在菜单内进入，分类横向滚动。

工作区首次进入、页面切换和统计数据刷新保留骨架屏；登录页与会话验证使用原来的居中圆形进度组件，追番动画搜索保留线性进度条、圆形进度及已加载数量，搜索结果封面使用主题色对角线渐变。其余页面、弹窗、图片预览与列表读取共用“展开内容”的纸张扫描动画，并按区域使用不同尺寸，跟随主题和减少动态效果偏好。设置页每次进入时显示读取状态；未访问的分类不加载表单代码，当前分类的模块进入视口后才挂载。已访问模块保留输入、草稿与对话框状态，离屏区域由浏览器跳过布局和绘制。文章编辑预览和模板、备份清单及偏好导入导出均按需准备，备份清单只在可见时读取；切换分类会返回顶部，未保存输入保留，离开设置页仍提示保存。

发布管理仅管理 Mizuki 项目的 Git 仓库：可查看当前分支、远程仓库、分页提交历史与文件差异，提交勾选的修改，并独立运行构建。所有操作显示运行日志。提交默认类型/作用域及日志偏好继续生效，操作说明见 [发布管理](PUBLISHING.md)。

## 保存与范围

每张卡片独立保存。“取消修改”恢复已保存值，“恢复本组默认”先填入默认值，仍需保存。外观等显示项提供即时预览，取消时还原。离开有未保存设置的页面会提示保存、放弃或继续编辑；部分保存失败时已保存组保留，失败输入仍在页面。

界面与编辑偏好保存在面板 `.local/personal-settings.json`，本机策略保存在 `.local/settings.json`，项目项保存在 `.local/project-settings/` 并按真实项目目录隔离；所有浏览器登录同一面板后共享这些设置。字体、外观、导航、通知、编辑器、AI 普通配置、草稿保存开关/延迟、日志显示及连接后页面均不再以浏览器存储为权威来源。登录页的显示缓存不影响已保存设置；清空缓存后登录仍会读取磁盘设置。首次登录且本机偏好文件不存在时自动导入原浏览器偏好；一旦本机文件存在，其他浏览器的旧缓存不再覆盖它。标题旁不显示范围标签，字段说明和目标项目提示说明影响。没有项目时仍可调整本机项。多浏览器修改同组产生冲突时，先核对提示再重载；不同组可分别保存。窗口重新获得焦点及每 30 秒会刷新公开偏好。

## 六类设置

| 分类 | 可调整功能 | 何时生效 |
| --- | --- | --- |
| 外观与导航 | 深/浅/系统主题、色相、面板/系统字体、界面字号、侧栏偏好、返回顶部开关/阈值、操作提示时长 | 显示即时预览；保存后跨页面使用。标题栏主题快捷入口直接保存 |
| 文章编辑 | 默认 Vditor 模式、正文/代码字体字号、行高、制表宽度、大纲默认状态/宽度、拼写检查、草稿、文章模板/命名 | 字体和显示原位更新；默认模式在下次打开文章时应用；模板只影响新文章 |
| 工作区 | 恢复上次/默认/不自动连接、最近项目数量及移除、连接后页面、项目只读 | 启动策略在下次启动服务时应用；只读由服务端执行，检测引起的只读不能被偏好解除 |
| 媒体管理 | 默认存储文件夹绝对路径、命名、引用格式、压缩、缩放、格式转换 | 上传时使用该文件夹，可临时选择项目内其他文件夹；替代文字自动使用文件名 |
| 预览与发布 | 预览端口/入口、日志字号/自动滚动/保留条数、提交类型/作用域默认值 | 端口在下次启动预览应用；日志显示即时更新；发布默认值只预填表单 |
| 备份与维护 | 备份/回收列表、恢复预览、手动清理规则、偏好导入导出/默认值、会话策略 | 恢复/清理经预览后执行；会话新策略在现有会话下一次请求应用 |

常用参数：界面字号 12—20px；正文 12—24px、行高 1.4—2.4；大纲 180—420px；代码可随正文或指定 10—24px；草稿延迟 1—10 秒。字体选择同步到编辑器正文、大纲、代码及新文章预览，项目字体来源仍可单独选择。

## 文章草稿与模板

草稿默认开启，延迟 2 秒，在当前浏览器 IndexedDB 保存完整文章与独立 Frontmatter。它不替代“保存正文”或 Ctrl+S。重新打开文章时可以查看差异、恢复到编辑区、暂不处理或丢弃；恢复后检查再手动保存。不同项目、文章和编辑标签页分别保存，磁盘更新不会被恢复直接覆盖。临时教程不生成文章草稿。

新文章模板分别填写正文、YAML 字段与文件名规则，可预览最终文件。占位符为 `{{title}}`、`{{date}}`、`{{year}}`、`{{month}}`、`{{day}}`、`{{slug}}`；日期使用当前系统 `YYYY-MM-DD`。默认字段含 title、published、pubDate、updatedDate、description、draft；标题/发布日期/草稿状态以创建表单为准。文件名只允许 `.md/.mdx` 且相对 posts，留空时手动指定；创建前仍检查 YAML、路径、重名和 URL 冲突。

## 工作区、媒体与任务

移除最近项目只删除记录；路径失效可先预览重新关联，不猜测覆盖已有设置。切换项目先处理未保存输入和运行任务：面板拥有的预览可明确停止，发布任务运行时拒绝切换。只读限制由服务端强制执行，个人偏好和允许的本机设置仍可调整。

媒体管理只保留“公共图片”入口，进入时使用与文章管理一致的加载动画，扫描完成后显示上传区域和文件夹网格。扫描整个 Mizuki 项目及已连接的内容仓库，按文件夹的绝对路径分组。文件夹默认使用该目录列表中的第一张图片作为封面，搜索不改变封面；空目录显示文件夹图标。文件夹卡片和封面根据当前视口挂载或卸载，保留等高占位以避免滚动跳动；键盘焦点所在卡片保持挂载。点击卡片进入目录，支持搜索、分页及返回文件夹列表，不再使用折叠面板。点击图片打开全屏查看器：支持放大、缩小、滚轮缩放、放大后拖动、双击缩放以及适应窗口；上一张和下一张可浏览当前目录搜索结果中的全部图片，不受分页限制。键盘 `←`/`→` 切换图片，`+`/`-` 缩放，`0` 适应窗口，`Esc` 关闭。图片加载和失败均有提示。扫描失败时可重试。排除 `dist`、`build`、`node_modules`、Git、缓存和面板状态目录，也识别 Astro 配置中的字面量 `outDir`/`cacheDir`。根目录、文档、`src/assets`、`public` 的图片均纳入列表；浏览器不支持的格式仍显示文件信息和占位。上传可选择已有文件夹或填写项目内新文件夹的绝对路径；不能指向项目之外、构建目录或通过链接越界。原先公共图片的子目录默认值兼容为对应的绝对路径。

图片处理默认关闭。开启后可预览目标尺寸、体积、完整目标路径和引用；不放大图片、不静默覆盖重名。动画/SVG 保持原样，透明图片不静默转 JPEG；失败需明确选择上传原图。公共目录图片复制站点 URL（不再局限 `/images/`），源码/文档图片复制实际文件路径，并提示按资源导入方式使用。媒体上传不提供替代文字输入框，自动使用文件名。引用检查覆盖文章、配置、源码与文档；仍被引用的图片不能删除，删除先进入回收目录。文章编辑器中的图片插入功能继续使用原有相对路径规则。

预览默认端口 4321（可选 1024—65535）。保存端口不重启现有任务；被占用时反馈错误，不自动终止其他进程。文章Mizuki预览 URL 优先于默认入口。关闭日志自动滚动可阅读历史行。发布默认值不会勾选文件或执行提交/推送，记忆只在明确提交成功后保存类型/作用域。

## 文章自动保存

在“文章编辑 → 文章自动保存”中开启后，选择仅正文、仅 Frontmatter 或两者一并保存，再选择离开时、定时或两者同时启用。点击“保存文章自动保存”后生效，默认关闭；定时间隔为 15—3600 秒，默认 60 秒。设置写入面板 `.local/personal-settings.json`，在不同浏览器中共享，并随偏好备份、导入导出和恢复处理。

自动保存直接写入文章文件，只提交所选部分有修改的内容；另一部分草稿继续保留。两者一并保存通过一次文件写入完成，生成一个备份和新的磁盘版本。复用正文源码片段、YAML 字段、必填项、路径及版本校验；遇到校验或磁盘冲突时保留输入、提示错误，同一失败草稿不再重复定时提交，修改草稿或手动处理版本后可重试。只读项目不自动写入；教程不参与自动保存；原始 Frontmatter 修复仍需手动保存。自动保存保持编辑器实例和撤销历史。

切换文章、返回列表、侧栏切换页面、浏览器后退和退出登录时，按设置等待自动保存完成。保存失败时停止页面切换；未选择保存的部分仍有修改时保留离开确认。浏览器关闭或刷新只能尽力使用后台请求保存，并保留未保存内容的原生离开确认；大于浏览器退出请求限制的内容需要先手动保存或通过页面导航离开。登录已过期时不能自动写入磁盘，使用现有的本地恢复流程。

“本地草稿”控制浏览器中的恢复副本，与磁盘自动保存独立，可同时启用。自动保存成功后更新基准、清理已保存的本次恢复副本；其他会话的副本保留。

## 备份、迁移与清理

列表可按归属、类型和原路径筛选，恢复先显示目标和版本；回收项不覆盖现有文件。旧备份缺少可确认的归属时受保护，不猜测恢复路径。工作区历史通过工作区重新关联功能处理。

手动清理规则默认关闭，参数为 30 天、每个原路径 20 项。开启后只产生手动预览，**没有后台清理**；需逐项勾选执行。最新恢复点、运行任务和归属不明项继续保留，预览过期或数据变更时重新检查。

偏好导出默认选择“界面与编辑偏好”，可另选本机策略/项目；为兼容旧文件，导出 schema 中仍使用 `browser` 范围名。它排除 API Key、令牌、Cookie、路径关联、正文与草稿。导入先展示分组差异，确认后写入 `.local` 并备份原文件，失败与成功分别报告；不自动连接项目或发布。批量恢复默认复用预览流程，不删除内容、备份或草稿。

普通设置保存前自动在 `.local/backups/settings/` 创建原文件备份，备份管理可以恢复 `personal-settings.json`、本机策略及项目设置。AI 配置和密钥另用 `.local/secure/ai-credentials.dpapi.json` 加密保存，修改前自动备份密文，文章编辑设置中的“创建加密备份”也可备份当前已保存版本。密钥不进入明文偏好导出；密文备份使用保存时的 Windows 账户恢复。所有这些本地文件和备份均被 Git 忽略，强制加入的密钥文件仍会被面板 Git 敏感检查拦截。

## 会话结束与恢复

“备份与维护”的闲置退出和最大有效期默认关闭。闲置参数默认 30 分钟，可选 5—240 分钟；最大有效期默认 24 小时，可选 1—168 小时。前者从最后实际输入、点击、触摸或滚动计算，后台日志/轮询不续期；后者从登录计算，持续操作也不续期。两项开启取较早期限。缩短策略可能使现有会话立即结束。

过期或手动退出前会保存当前正文与 Frontmatter 的本地恢复副本。草稿关闭、存储失败/超时、其他表单未保存时保留输入，并提供重试、下载副本、明确放弃；手动退出还可继续编辑。退出不停止后台预览和发布，重新登录后继续查看任务。

文章草稿可在原文章恢复。下载的会话恢复 JSON 是紧急输入副本，没有整体自动导入入口：文章使用其中 `source` 和 `frontmatter` 手动恢复，其他资源按标记复填；设置条目的 `data` 可单独另存为偏好 JSON，再通过“选择偏好文件”核对差异导入。文件含未保存内容，应保存在自己的设备。清除浏览器站点数据只移除显示缓存和该浏览器的未保存文章草稿，`.local` 中已保存的设置和加密密钥不受影响。草稿仍是浏览器内的未保存内容恢复机制，AI 对话仍仅在页面内存中，两者不包含在普通设置备份中；保存正文后文章写入项目磁盘。

升级随机会话 ID、重启面板或轮换访问令牌后需重新登录；已有文章、偏好和本地草稿仍保留。会话策略文件不可读或不兼容时会显示错误，先修复权限或使用兼容版本，不通过删文件绕过。

设计与各阶段验证见 [实施规划](PANEL_SETTINGS_STAGES.md)、[最终实现说明](PANEL_SETTINGS_STAGE_8.md)。


“备份与维护”中的“备份管理”和“回收站”分开显示，各自保留归属筛选、路径搜索、数量和占用统计、恢复与手动清理预览。两个模块按视口加载，已输入的筛选条件不会因滚动丢失；操作完成后会刷新相关列表。回收站清理只包含回收项，备份清理只包含保存备份，预览令牌也限制对应类型，不能用回收站预览清理备份。两者继续共用现有保留规则及最新恢复点保护。删除文章后的恢复入口为“设置 → 备份与维护 → 回收站”。

回收站统一存储在面板状态目录的 `recycle-bin/`（默认 `.local/recycle-bin/`），按 `articles`、`features`、`media` 分类。选择移入回收站时移动原文件或整个目录，并保存原路径、项目归属、删除时间和内容摘要；跨磁盘时复制并校验完整内容后再移除原文件。选择永久删除不会创建回收项。数量仅包含专用目录内有回收记录的实际文件或目录，一份目录计为一项，占用统计其完整内容，不含元数据文件。旧 `.local/trash/` 保留原样，不自动迁移，也不再计入回收站；缺少回收记录的文件不计入，损坏的已登记回收项受保护。自动化测试使用独立临时状态目录，结束后清理，不能写入正在使用的面板回收站。
