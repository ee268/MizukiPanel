# 阶段 6：全部特色页

阶段 6 已完成关于、友链、日记、追番、相册、项目、技能、设备、时间线和 AI 工具的统一管理。

## 管理范围

- 关于正文复用 Vditor Markdown 编辑器，支持格式工具栏、大纲、全屏、公共图片与 URL 插图、保存快捷键、首次创建、版本冲突检查及撤销保存。保存和退出前同步尚未回传的输入，沿用文章编辑器的字体与主题偏好。
- 友链配置只显示友链列表，不再提供友链说明入口；既有 `spec/friends.md` 文件保留。
- 友链、日记、本地追番、项目、技能、时间线和 AI 工具每页默认显示 5 条，可切换为 10 或 20 条。翻页保留整份未保存数据，保存校验全部页；添加或跨页排序时自动定位目标页，错误 JSON 自动定位到所在页。
- 相册列表默认每页 5 条，季度文件按年份折叠、每页 5 年，每年按 1、4、7、10 月排序；相册本地图片每页 10 条。分组 JSON、相册信息及季度正文限制编辑区高度，在区内滚动。只读项目可翻页、展开年份和选择查看，但修改操作不可用。
- 列表条目、设备分组和相册信息的 JSON，以及季度 Markdown，统一使用 CodeMirror 语法编辑器，提供行号、折叠、括号匹配、缩进和深浅色高亮。季度编辑器同时识别 YAML Frontmatter 与常见代码块。字体沿用设置中的全局字体，编辑区保持高度限制，分页不丢失未保存输入。
- 结构化数据：管理 `friends.ts`、`diary.ts`、`anime.ts`、`projects.ts`、`skills.ts`、`devices.ts`、`timeline.ts` 和 `ai-tools.ts`。
- 数组数据以独立条目显示，支持新增、修改、删除和上下排序；设备分组以结构化 JSON 编辑。
- 使用 TypeScript AST 只替换目标数据初始化器，保留接口、导入、辅助函数和未触及代码。
- 季度追番：仅在当前内容源存在 `animes/` 目录时显示，替代本地追番入口；本地模式检测 `src/content/animes/`，独立模式检测内容仓库的 `animes/`。空目录保留季度编辑器，支持新建及删除最后一条后的继续管理。管理 `animes/<年>/<季度>月.md`，支持创建、编辑和移入回收目录。
- 新建季度通过年份和月份选择，月份限定 1、4、7、10 月，已有季度禁止重复创建。模板自动生成 `cover: http:://example.com`、`title: YYYY年M月新番`、`date: YYYY/MM/01`，`author` 沿用最近有作者的季度文件；没有历史作者时为空，可在编辑器中填写。模板不含 `comments`、`copyright`，保存时也移除这两个顶层字段，保留正文及其他元数据。
- 相册：管理 `images/albums/<id>/info.json`，支持本地/外链模式、隐藏、布局、封面、照片、密码字段、图片上传和可恢复删除。
- 页面目录使用搜索栏和紧凑卡片网格，支持联想搜索、中文输入法、滚动入场和按需挂载；打开过的编辑器在返回目录后保留草稿与撤销记录，详见 [特色页面布局](FEATURE_LAYOUT.md)。
- 页面状态：读取 `siteConfig.featurePages` 和 `navBarConfig`，卡片开关直接保存对应字段，自动备份并校验配置版本；关于页保持常开。关闭页面仍可编辑，详情提示缺少导航入口。
- 外部数据源：Memos、Bangumi 和 Bilibili 模式只显示来源状态并引导到站点配置，不修改未生效的本地数据。

## 安全与校验

- 本地模式写入 Mizuki 仓库；独立模式写入内容仓库的 `spec/`、`data/`、`animes/` 和 `images/albums/`，页面开关写入 `overrides/siteConfig.ts`。
- 所有写入复用路径守卫、版本哈希、原子替换和备份。
- 校验重复 ID、日期、HTTP(S) URL、站点相对路径、季度文件名和相册字段。
- TypeScript 数据出现代码表达式时切换为只读，避免把表达式错误转换为字符串。
- 季度文件、相册目录和相册图片删除前复制到面板回收目录。

## 验证

- 真实 Mizuki：10 个模块、8 个结构化数据源、2 个正文、11 个季度文件和 4 个相册全部完成只读解析。
- 测试夹具：本地与独立模式的数据保存/恢复、正文创建、页面开关、导航状态、远程数据源、季度创建/删除、相册创建/修改/删除。
- 面板通过 `pnpm check`、`pnpm test` 和 `pnpm build`。
- Mizuki 通过 `pnpm check`、`pnpm type-check` 和 `pnpm build`。
