# 阶段 4：媒体与真实预览

## 已实现

- 媒体中心浏览、筛选和预览公共图片与文章资源。公共图片写入 `public/images/`（独立内容模式为 `images/`），文章资源写入所选文章的同级目录。
- 上传支持 PNG、JPEG、GIF、WebP 和 AVIF，单文件最大 20 MB。服务端同时校验扩展名和文件签名，拒绝空文件、路径穿越、Windows 保留名、符号链接越界和同名覆盖；上传先写临时文件，再以排他方式落盘。
- 上传完成后返回可直接粘贴的引用。公共图片使用 `/images/...`，文章资源按所属文章生成 `./...` 相对路径；媒体列表会为嵌套文章重新计算正确引用。
- 删除前扫描 Markdown 与 MDX 文章中的已知引用。仍被引用的图片不能删除；可删除图片会先复制到 `.local/trash/media/`，原文件删除失败时同时撤销回收副本。
- 真实预览页直接启动项目已安装的 Astro CLI，默认监听 `127.0.0.1:4321`，显示启动状态和最近 300 行去 ANSI 日志。端口、路径与日志偏好现已在 [设置阶段 6](PANEL_SETTINGS_STAGE_6.md) 接入。也可连接已运行的外部 HTTP 服务；面板只停止自己直接启动并持续跟踪的进程。
- 文章编辑页可按 Mizuki 的实际 slug 规则打开对应预览路径。预览嵌入真实 Astro 页面，也可在新窗口打开，Markdown、MDX、remark/rehype 插件和主题样式均由 Mizuki 自身处理。

## 操作说明

1. 连接工作区后打开“媒体”，选择公共图片或文章资源。文章资源必须选择所属文章，上传结果中的引用可直接复制到正文。
2. 打开“真实预览”，启动 Astro 后输入 `/posts/<slug>/` 等站内路径。文章编辑页的“真实预览”会自动带入当前文章路径。
3. 独立内容模式仍遵守阶段 2 的显式同步边界。面板不会在启动预览时暗中执行同步脚本；使用复制回退的工作区应先运行 Mizuki 的安全 `pnpm sync-content`，再启动预览。目录联接模式中的源文件会直接反映到预览。

## 安全边界

- 图片响应要求已登录会话，并返回 `private, no-store` 和 `X-Content-Type-Options: nosniff`。
- 预览服务仅绑定回环地址，不接受面板输入的命令、可执行文件路径或端口。
- 端口已有服务时只读连接，避免终止非面板进程。面板进程被强制结束时，操作系统可能留下 Astro 子进程；可重新打开面板连接，或在终端结束该 Astro 开发服务。
- 引用检查覆盖文本中可识别的相对路径和 `/images/` 路径。运行时拼接的动态路径无法静态确认，删除前仍应查看 Git 差异。

## 验证

- `pnpm test`：18 项测试通过，媒体测试覆盖本地/独立内容模式、嵌套文章相对引用、实际文件类型、重复上传、只读状态、引用阻止删除和回收副本。
- `pnpm check`：React、Hono 与 TypeScript 检查通过，无错误。
- `pnpm build`：Node 适配器生产构建通过。
- 真实运行验证：从生产构建登录面板，经表单分别创建临时 Markdown 与 MDX 文章并上传文章 WebP 与公共 WebP；由面板启动 Mizuki Astro，两种文章页均返回 HTTP 200。MDX 表达式、提示指令、文章相对图片和 `/images/` 公共图片均出现在真实渲染结果中。验证后通过面板删除动作清理临时内容并关闭测试进程。
