# 关于页布局

关于页正式采用杂志阅读布局，入口为 `/about`。顶部方案选择控件与其他候选布局已移除，旧链接中的 `layout` 参数不再改变页面样式。

桌面使用固定章节目录、分栏功能介绍、交互流程、可折叠问答和项目入口。目录平滑定位并避开标题栏，手机切换为顶部目录。功能卡片提供悬浮抬升与图标轻旋，正文区块滚动显现，流程与问答内容以过渡动画切换。

公共内容与开源地址集中在 `src/client/about/content.ts`，开源入口与复制按钮统一使用 `https://github.com/ee268/MizukiPanel`。功能卡片、展厅与流程均可直接进入对应页面。

页面跟随面板的字体、字号、主题色和深浅色。移动端使用单列功能卡片。系统启用减少动画时停止装饰漂浮、入场、悬浮位移和切换动画，章节定位使用直接滚动。流程支持左右方向键、Home 和 End，问答支持键盘操作。

页面职责划分：`AboutPage.tsx` 提供页面容器，`AboutEditorial.tsx` 组织阅读布局，`AboutSections.tsx` 提供公共展示与交互区块，`AboutMotion.tsx` 提供滚动显现和动画样式。
