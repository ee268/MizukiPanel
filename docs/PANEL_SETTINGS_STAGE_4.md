# 设置阶段 4：工作区与启动偏好

完成日期：2026-10-09。设置入口：`/settings?section=workspace`。

## 功能与默认值

| 设置 | 默认值 | 生效方式 |
| --- | --- | --- |
| 启动时连接 | 恢复上次连接 | 本机保存，下次启动面板服务时应用 |
| 默认项目 | 未指定 | 选择已连接过的项目；路径失效时提示，不回退到其他项目 |
| 最近项目数量 | 10 | 允许 1—50；保存后立即调整显示数量，下次连接截取最近列表 |
| 连接后的页面 | 项目工作区 | 浏览器保存，手动连接/切换成功后应用 |
| 项目只读偏好 | 关闭 | 项目保存，服务端立即约束写入；检测产生的只读仍然有效 |

各分组提供保存、取消、恢复本组默认、未保存提示与冲突保护。启动偏好保存不会改变当前连接。连接后的页面可选工作区、文章、配置、特色页、媒体、预览和发布。只读项目仍可调整面板偏好、查看内容及 Git 状态与差异。

## 会话、记录与兼容迁移

服务启动时建立一次工作区会话，启动策略只在此时应用；后续请求读取当前会话，不根据启动偏好反复连接。断开会清空“上次连接”，但保留最近记录和默认项目。默认策略仍会在下一次启动连接所选默认项目。

首次读取时，将旧 `.local/workspace.json` 的绝对路径迁入 `.local/workspace-history.json`。旧文件原样保留；新文件存在后以新记录为准，不再反复导入旧路径。旧路径无法验证时也保留记录，供用户修复。目录不可用、非 Mizuki 项目、路径标识变化和缺失默认项目均提供明确错误。

记录包含 schema 版本、修订、规范化项目路径、最近使用时间、项目标识和最近顺序。项目标识与项目设置继续使用真实根目录哈希。最近列表去重并按使用顺序更新；已知路径表保留独立记录，使默认项目或原项目设置不会因列表截取/移除而丢失。移除只修改最近列表，不删除项目、文章、设置或默认关联。

历史记录的写入沿用文件锁、内容版本比对、备份和原子替换，备份位于 `.local/backups/workspace`。损坏/未来版本历史保持原样并暂停自动连接及记录写入；仍可手动建立仅当前服务会话有效的连接，页面显示警告。未来版本本机设置暂停自动连接，并保留原设置。没有项目时，浏览器与本机偏好仍可使用；工作区状态读取失败时也保留浏览器设置入口。

## 路径重新关联

最近项目提供“重新关联”，当前连接项需要先断开。先选择新路径，再显示原路径、新的真实路径、项目标识对应关系、是否复制设置以及是否更新默认项目，最后明确应用。

新项目必须通过 Mizuki 检测。预览绑定历史、本机设置及两份项目设置的版本；过期预览拒绝应用。目标没有设置时复制原设置的完整原文，保留未知字段和旧副本；目标已有设置时保留目标设置。原记录继续留在已知路径表中，最近列表、上次连接和默认关联按需更新，项目文件不会移动。

设置复制、历史更新和默认偏好属于多个文件，无法组成跨文件事务。中途失败会说明已完成的部分，不宣称全部成功；原记录与设置副本保留，可刷新后核对和重试。测试覆盖默认设置锁冲突后的部分成功反馈。

## 切换、运行任务与多标签页

先验证目标项目与设置，再处理运行任务和保存连接。发布操作运行期间拒绝切换/断开。切换到其他项目或断开时，面板拥有的预览需要在对话框中明确停止；目标无效时不停止当前预览。外部进程不被关闭。预览停止未完成或记录写入失败时不改变当前连接。

设置页有未保存内容时禁用连接、移除和关联操作，保存/取消后再执行。浏览器、本机和项目设置共用导航/退出/卸载保护，部分保存失败保留剩余输入。文章继续使用既有离开提醒和 IndexedDB 恢复副本。

每次连接/断开都会更新服务会话版本。客户端请求携带读取页面时的 `X-Mizuki-Workspace`；写入必须带版本，服务端在串行写入队列内核对，过期请求返回 409，即使文章路径与文件版本相同也不会写入其他项目。认证请求独立处理，文件/图片的普通 GET 保持兼容。

当前标签页完成切换后更新连接并重建页面；其他标签页通过 BroadcastChannel、焦点和 15 秒状态刷新发现变化，保留原输入、显示提醒，由用户重新载入。旧页面不会自动接受新的写入目标。读取中的旧响应不会覆盖已确认的新连接。只读变化保持会话版本，原位同步文章编辑器、配置、媒体、特色页和发布按钮，不重建编辑器或丢失未保存正文。

## 只读约束

实际只读状态合并项目检测、项目 `access.readOnly` 偏好和不可识别/未来版本项目设置的限制。设置页分别说明检测和设置来源；关闭偏好不会解除检测限制。所有文章、配置、媒体、特色页和发布修改继续由服务端校验。只读项目仍可保存面板项目元数据，从而关闭自己开启的只读偏好；未来版本设置本身不能被旧面板覆盖。
