# 设置阶段 7：备份维护与偏好迁移

完成日期：2026-10-10。入口为“设置 → 备份与维护”。阶段 8 的会话策略尚未开始。

## 使用方式

“备份与回收”显示所有恢复项的类型、原路径、归属、保存时间、体积和恢复条件，可按当前/指定项目、本机、归属未知、类型和路径筛选。总占用统计所有列表项的内容体积，不含元数据文件；无法安全扫描的目录会警告并保留，体积不可确认。

选择“预览恢复”后检查原路径、时间与体积，再明确确认。保存备份恢复前核对当前文件版本，并先备份当前内容。回收项仅恢复到不存在的原路径；相册恢复完整目录，图片保留原始字节。恢复副本继续保留，避免恢复后失去原恢复点。

旧裸备份和损坏/被修改的恢复数据不会推测项目或原路径，不提供恢复与规则清理。工作区历史备份保留并显示条件；工作区连接状态使用既有“重新关联项目”流程处理，不能通过直接覆盖历史文件改变当前运行状态。跨项目恢复、内容根目录变更、只读项目内容恢复、任务运行时恢复均被拒绝；本机和项目偏好仍可按既有范围规则调整。

## 保留与清理

保留规则默认关闭，默认 30 天/每个原路径 20 项，范围分别是 1—3650 天、1—1000 项。关闭时所有恢复项保留。开启后仅计算手动清理候选，不注册定时任务、不自动删除。

同一项目、管理根目录和原路径按备份/回收分别排序；每组最新恢复点始终保留，最新时间相同时保留全部并列项。早于保留期限或超出保留数量的旧项可进入预览，运行任务、归属未知和损坏数据受保护。预览汇总全部项目与本机，必须逐项勾选后执行；列表筛选不隐含清理授权。

预览有效 10 分钟，绑定恢复清单、内容摘要、项目和保留设置版本。数据、规则、任务状态变化或服务重启后必须重新预览。执行前检查全部选择，之后逐项报告成功/失败；不会把部分完成报告成全部成功。恢复、清理与其他工作区写入沿用串行请求保护。

## 偏好迁移与默认值

导出默认为浏览器，可以显式增加本机与当前项目。版本化 JSON 仅包含当前设置 schema 的白名单字段，排除凭据、Cookie、项目路径关联、默认项目标识、正文、草稿及恢复文件。文章模板属于设置，可随项目偏好导出。默认项目启动策略因排除关联而导出为“不自动连接”；其他启动策略按原值导出。

导入拒绝未知范围/分组/字段、无效值、项目关联字段、不兼容版本和超过 1 MiB 的文件。先展示范围、分组及字段差异；默认勾选浏览器分组，其他范围需明确选择。项目范围绑定预览时的当前项目，导入不连接项目、不发布、不写入正文。对只读内容项目仍可迁移面板项目偏好，检测引起的内容只读限制不会被偏好解除。

每个范围内的所有所选分组先完整校验，再一次保存并备份。浏览器使用既有 Web Locks/分组基准检查，备份失败即停止；服务端使用文件版本、文件锁及原子替换。跨范围独立执行，界面分别报告成功/失败，失败分组继续保留且不会重放成功范围。文件或项目已变化时拒绝旧预览。

“预览批量恢复默认”复用上述选择和差异流程，只修改所选设置。默认项目关联保留；文章、媒体、项目目录、IndexedDB 草稿和草稿恢复记录不受影响。已有各设置卡片的分组默认值预览及保存继续可用。其他设置尚未保存时禁止迁移、恢复和清理，避免覆盖表单输入。

## 存储与实现

新保存备份和回收项使用同名 `.meta.json` 侧车记录 schema、类型、时间、项目身份、真实管理根目录、原相对路径、字节数、目录类型和 SHA-256 内容摘要。文件和目录均完成复制、记录及校验后再替换/删除原内容；元数据失败时停止原文件修改。恢复入口只接收服务端枚举的标识和预览令牌，不接收任意文件系统路径。原配置/特色页恢复入口也核对新备份归属，不能拿其他项目或资源的备份写入当前文件。

归属使用真实项目路径的稳定哈希；独立仓库另核对真实内容根目录。扫描拒绝符号链接/特殊文件，清理限定面板状态目录，恢复限定当前资源白名单。目录摘要采用稳定排序和流式文件哈希；单项扫描限制 1 GiB/10000 项/32 层，恢复列表最多 2000 项、备份目录扫描最多 4 层，元数据最多 64 KiB。通用文本备份恢复上限 20 MiB；超过限制的数据保留并提示手动处理。

备份、回收和设置共享当前请求的状态目录上下文；自定义实例目录不会写到默认实例。新增 `machine.maintenance` 属于兼容的 schema 1 扩展，旧设置读取补齐默认值，不立即回写。

主要模块：`archive-metadata`、`maintenance` 与维护路由；`preferences-transfer` 与分组批量保存；`MaintenanceSettingsForms`、`PreferenceTransferForm` 和浏览器保存副本逻辑。
