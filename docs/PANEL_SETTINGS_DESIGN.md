# MizukiPanel 设置页设计文档

设计版本：v1  
设计日期：2026-10-09  
状态：阶段 1—8 已完成（2026-10-10）

范围来源：已采纳的 [设置规划](PANEL_SETTINGS.md)  
实施顺序：[八阶段规划](PANEL_SETTINGS_STAGES.md)

## 1. 目标与现状

设置页统一管理 MizukiPanel 的个人偏好、项目使用偏好和面板运行选项。入口位于侧栏底部、关于入口上方，路由 `/settings` 沿用登录校验；页面具备六类导航和内容区域，桌面纵向排列，窄屏横向滚动。阶段 1—8 已接入外观导航、编辑器、草稿模板、工作区、媒体、预览发布、备份迁移和会话策略；编辑器预览不写入文章。后续章节保留整体设计，实际交付和最新校准见 [阶段规划](PANEL_SETTINGS_STAGES.md)、[阶段 8 说明](PANEL_SETTINGS_STAGE_8.md) 及 [设置使用说明](PANEL_SETTINGS_USAGE.md)。

本轮开发的目标是让用户明确知道每项设置影响哪里、何时生效，以及如何恢复默认。Mizuki 博客内容和站点配置仍由原功能页管理。设置页不恢复已移除的独立完整源码编辑器，也不改变正文手动保存、真实发布由用户触发的工作方式。

## 2. 页面与交互

### 2.1 分类与布局

保留以下分类：

| 分类 | 内容分组 |
| --- | --- |
| 外观与导航 | 显示模式、主题色、界面文字、导航习惯、操作提示 |
| 文章编辑 | 编辑模式、字体与代码显示、大纲、草稿恢复、新文章模板 |
| 工作区 | 启动项目、最近项目、连接后行为、只读偏好 |
| 媒体管理 | 上传位置、文件命名、图片引用、图片处理 |
| 预览与发布 | Astro 预览、日志显示、发布表单默认值 |
| 备份与维护 | 备份、回收内容、占用统计、偏好迁移、会话管理 |

每类由独立分组卡片组成，标题右侧不显示保存范围标签。项目项显示目标项目；未连接项目时保留说明和连接工作区的入口，禁用相应表单。分类使用稳定 ID，可通过 `/settings?section=editor` 等地址进入；未知分类回退至外观，不清空数据。

桌面维持左分类、右表单；移动端使用横向分类和单列表单，操作按钮可换行。提供明确的标签、说明、错误关联及键盘操作，不依赖悬停显示关键含义。沿用 Material UI 和面板现有深浅色主题。

### 2.2 修改、保存和恢复默认

- 每张分组卡片独立编辑和保存，显示“保存设置”“取消修改”“恢复本组默认”。保存提交该组字段，避免覆盖其他分组。
- 字段修改后标记未保存；无修改时保存和取消禁用。恢复默认先填入默认值，点击保存后才持久化。
- 外观在编辑期间提供即时预览，取消、切换分类或离开时恢复已保存外观。切换分类/页面存在未保存项时提示保存、放弃或继续编辑。
- 项目或本机设置保存失败时保留输入，显示具体失败原因；版本冲突时提供重载和比对入口，不自动覆盖。
- 标题栏主题入口继续作为快捷入口，与设置页复用同一主题状态和控件。快捷入口保持即时生效、即时保存；设置页若正在编辑主题草稿，外部已保存值变化时提示并要求重新载入该组。
- 每项说明生效时间。文字和颜色可即时更新；编辑模式、模板、上传默认值在下一次打开对应功能时应用；预览端口在下次启动预览时应用。

批量恢复、导入、草稿丢弃、备份清理等操作先展示具体范围和影响，再由用户触发。退出登录保留个人偏好和本地草稿，不自动清空正文。

## 3. 保存范围与数据模型

### 3.1 三种设置范围

| 范围 | 保存位置（拟定） | 典型内容 | 共享规则 |
| --- | --- | --- | --- |
| 当前浏览器 | `localStorage` 中的版本化个人偏好 | 主题、字号、侧栏、编辑显示、日志显示 | 同源同浏览器标签页同步；不同浏览器独立 |
| 当前项目 | 面板 `.local/project-settings/<projectKey>.json` | 模板、命名规则、媒体目录、预览路径与端口 | 当前面板进程的各浏览器共享；按项目隔离 |
| 本机面板 | 面板 `.local/settings.json` | 启动项目、最近项目、备份策略、会话策略 | 各浏览器共享；不写入 Mizuki 或内容仓库 |

`projectKey` 由服务端规范化的真实项目根目录生成稳定标识，复用现有路径处理。浏览器不能直接提交任意设置文件路径。别名路径连接同一项目时应解析为同一标识；目录搬迁后通过工作区重新关联，避免错误继承旧项目设置。

新增文件继续位于 Git 忽略的面板状态目录，独立内容仓库模式也采用相同规则。项目自身只读或用户启用只读偏好时，仍可修改面板偏好，但文章、站点配置、媒体、同步、提交、推送和构建等业务写入保持禁用。

配置封套包含 `schemaVersion`、`revision`、`updatedAt` 和分组 `values`。默认值集中定义；每字段只有一个所属范围。个人显示偏好从浏览器读取，项目默认值从项目文件读取，本机策略从面板文件读取，三类设置按领域组合，不允许浏览器覆盖本机的路径、会话或保留策略。

### 3.2 读取与迁移

1. 无配置时按当前行为填入默认值，不立即生成文件。
2. 旧 `mizuki-panel-theme` 的模式和色相迁入个人偏好，已存在的新值优先；旧键只在迁移成功后清理。
3. `.local/workspace.json` 的当前项目路径先保持兼容，启动策略接入时显式迁移，不丢失现有连接。
4. 枚举、数值、路径、模板和 JSON 结构分别校验；无效的单字段回退默认并提示，不导致整个页面无法打开。
5. 版本迁移按 `schemaVersion` 执行，保留迁移前副本；遇到更高版本时只读并提示，避免降级重写。
6. 浏览器存储被禁用或额度不足时允许临时使用偏好，并明确显示无法保存；服务端状态损坏时保留原文件，提供恢复入口。

### 3.3 接口与模块边界（拟定）

| 接口 | 职责 |
| --- | --- |
| `GET /api/settings` | 读取本机设置、连接项目的设置、版本和可用能力 |
| `PATCH /api/settings` | 提交指定范围/分组的字段及预期版本，服务端校验后原子保存 |
| `GET /api/settings/projects` | 获取最近项目、默认项目及可读取状态，不建立连接 |
| `GET /api/maintenance/items` | 按项目和类型列出备份/回收项、占用和恢复条件 |
| `POST /api/maintenance/restore` | 按已列出的 ID 恢复，复用业务版本与路径校验 |
| `POST /api/maintenance/cleanup-preview` | 预览保留策略将影响的文件与占用，不删除 |
| `POST /api/maintenance/cleanup` | 按有效预览版本和明确选择执行清理 |

客户端继续使用 `api.ts`，服务端沿用现有安全中间件的登录与来源校验。业务服务负责范围、校验、迁移和原子写入，路由只完成请求/响应映射。保存请求携带范围、分组和预期版本，项目项额外携带读取时的项目标识；目标项目已切换或版本过期时返回冲突，不将迟到保存应用到新项目。清理预览过期或目标状态变化时必须重算，不继续使用旧列表。

已建立模块：`src/shared/panel-settings/` 放序列化类型、字段校验和默认值；`src/lib/server/panel-settings.ts` 管理本机/项目偏好；`src/server/routes/settings.ts` 提供接口；`src/client/settings/` 管理状态、分类表单与共享控件。共享定义不依赖 React、Hono 或文件系统。草稿、维护、图片处理和会话的业务逻辑各自独立，不全部堆入设置页。

## 4. 设置项与拟定默认值

下表参数为 v1 设计默认值，实施时结合当前实现和浏览器验收校准；已有偏好迁移后优先使用原值。

### 4.1 外观与导航

| 设置项 | 范围 | 默认/约束 | 生效方式 |
| --- | --- | --- | --- |
| 显示模式 | 浏览器 | 跟随系统；支持浅色、深色 | 即时，主题预览可取消 |
| 主题色相 | 浏览器 | 240°；0—360，保留现有用户值 | 即时 |
| 界面字体 | 浏览器 | 现有面板字体；可选系统字体 | 即时；字体缺失显示回退状态；系统字体同时覆盖编辑器正文/行内代码的项目字体，代码块仍使用独立等宽字体 |
| 界面字号 | 浏览器 | 当前主题基准字号；可调 12—20px | 即时，不硬改图标或触控尺寸 |
| 默认侧栏 | 浏览器 | 折叠；可选展开/记住上次 | 下次加载；移动端保持抽屉模式 |
| 返回顶部 | 浏览器 | 开启；显示阈值 240px，可调 100—1000px | 即时，保留编辑器全屏滚动支持 |
| 操作提示时长 | 浏览器 | 3500ms；可调 2000—10000ms | 下一条成功/信息提示；错误不强制自动关闭 |

### 4.2 文章编辑

| 设置项 | 范围 | 默认/约束 | 生效方式 |
| --- | --- | --- | --- |
| 默认编辑模式 | 浏览器 | 按格式自动：Markdown 即时渲染、MDX 分屏、教程即时渲染；可指定即时渲染、所见即所得、分屏 | 下次打开文章；MDX 显示能力说明 |
| 大纲显示与宽度 | 浏览器 | 默认关闭、250px；可调 180—420px，窄屏收起并约束宽度 | 即时调整，不重新初始化正文；工具栏临时切换不写入偏好 |
| 正文字体来源 | 浏览器 | 跟随当前项目；可选系统、面板内置字体 | 即时；明确选择优先；跟随项目时仍遵循界面系统字体，不写入站点配置 |
| 正文字号/行高 | 浏览器 | 16px / 1.85；12—24px / 1.4—2.4 | CSS 更新，保持光标与历史 |
| 代码字体/字号/制表宽度 | 浏览器 | 项目/面板/系统等宽字体；字号默认正文的 85%，可指定 10—24px；制表宽度 4，可选 2/4/8 | 显示层更新，不改写代码缩进；分屏源码沿用代码字体和字号 |
| 拼写检查 | 浏览器 | 关闭 | 使用浏览器能力，不接入外部校对服务 |
| 本地草稿保存 | 浏览器 | 开启；输入停止 2 秒后保存，可选 1—10 秒 | 仅保存恢复副本，不调用文章写入 API |
| 未保存提醒 | 浏览器 | 保留现有离开提醒；可增加保存状态提示 | 草稿持久化失败时仍提示未保存 |
| 新文章模板与命名规则 | 项目 | 沿用现有标题、日期、草稿及正文结构 | 仅影响后续新建；当前文章保持原样 |

模板使用受支持的字段占位符，如标题和创建日期，不执行 JavaScript 或任意表达式。默认 Frontmatter 字段保留未知字段的兼容性，必填值由现有文章校验负责。文件名规则校验扩展名、路径和 URL 冲突，预览最终文件名后再创建。

行内代码继续使用当前正文字体；代码块使用独立代码字体；反引号保留现有符号补救字体。链接虚线、主题色、加粗中性色、浅色代码背景和合法 HTML 图片识别沿用当前规则。修改偏好不能替换 Vditor 运行时类、重建编辑器或丢失撤销记录；构造时才能生效的项推迟到下次打开。

### 4.3 工作区

| 设置项 | 范围 | 默认/约束 | 生效方式 |
| --- | --- | --- | --- |
| 启动项目策略 | 本机 | 恢复上次项目；可选指定默认项目、不自动连接 | 下次启动；失败时保留设置并展示错误 |
| 最近项目 | 本机 | 最多 10 项；支持移除记录和设为默认 | 移除记录不删除项目文件 |
| 连接后页面 | 浏览器 | 工作区；可选文章管理等稳定页面 | 用户完成连接后应用 |
| 项目只读偏好 | 项目 | 关闭；检测导致的只读不可通过此开关解除 | 服务端执行，显示只读来源 |

默认项目未找到时不静默连接另一个项目。切换项目前处理未保存正文、设置和运行中的预览任务，沿用现有操作边界。

### 4.4 媒体管理

| 设置项 | 范围 | 默认/约束 | 生效方式 |
| --- | --- | --- | --- |
| 默认上传范围与目录 | 项目 | 公共资源；沿用现有目录填写规则 | 下一次上传，可在表单临时覆盖 |
| 文件命名 | 项目 | 保留原文件名；可选日期前缀或唯一名称 | 上传前展示结果；重名不默认覆盖 |
| 图片引用方式 | 项目 | 根据上传范围生成公共/文章相对路径 | 不批量重写已有引用 |
| 默认替代文字 | 项目 | 沿用现有插入规则；可选文件名或留空 | 插入前可编辑，区分装饰性图片 |
| 图片压缩 | 项目 | 关闭；启用后质量默认 85，可调 50—100 | 上传前处理，显示原始/处理后大小 |
| 最大尺寸与转换格式 | 项目 | 不限制、不转换；启用缩放时长边默认 1920px | 保持比例，不放大，不默认丢弃透明度 |

压缩/缩放/格式转换需要新增图片处理能力，第 5 阶段评估实现依赖并验证格式和平台支持。GIF 动画、SVG、无法可靠解码的文件默认不转换，给出跳过原因；失败可选择上传原图。执行处理前限制文件体积、像素规模和耗时。文章只读仍禁用上传，处理参数不能绕过现有媒体路径约束。

### 4.5 预览与发布

| 设置项 | 范围 | 默认/约束 | 生效方式 |
| --- | --- | --- | --- |
| Astro 预览端口 | 项目 | 4321；拟定允许 1024—65535 | 下次启动；运行中保存显示尚未应用 |
| 默认预览路径 | 项目 | `/`；文章入口继续使用文章真实路径 | 下一次进入预览；保留临时输入 |
| 外部服务连接 | 项目 | 保留现有本机端口探测；明确显示是否为面板启动的进程 | 外部进程不提供停止操作 |
| 预览日志保留条数 | 本机 | 300；拟定 100—5000 | 后续日志追加时执行 |
| 日志自动滚动与字号 | 浏览器 | 开启；保留当前字号 | 即时，关闭后不抢阅读位置 |
| 发布表单默认值 | 项目 | 默认不记忆；启用后在提交成功时记住提交类型、作用域，提交正文保持空白 | 仅填充界面；新打开时文件选择为空，保存设置不执行发布 |
| 发布日志显示与保留 | 浏览器显示偏好/本机条数，分别存储 | 字号与自动滚动规则同预览日志；发布日志条数默认 500，拟定 100—5000 | 显示即时生效，保留限制在后续追加时应用 |

固定 Git 超时、最大差异大小等内部限制暂不作为普通设置项。提交、推送、同步、构建和回退仍由明确操作触发；不提供保存设置后自动执行发布的选项。面板监听地址、API 端口和访问令牌继续通过启动配置管理。

### 4.6 备份、迁移与会话

| 设置项/功能 | 范围 | 默认/约束 | 生效方式 |
| --- | --- | --- | --- |
| 备份管理 | 本机，按项目筛选 | 仅列出保存备份，独立搜索、统计、恢复与清理预览 | 用户选择后恢复，先检查目标版本 |
| 回收站 | 本机，按项目筛选 | 仅列出回收项，独立搜索、统计、恢复与清理预览 | 只能恢复到不存在的原路径，清理不包含备份 |
| 保留策略 | 本机 | 默认关闭；30 天/20 项，允许 1—3650 天/1—1000 项 | 只计算手动清理预览；未启用时全部保留，无后台清理 |
| 清理 | 本机 | 显示对象、数量、体积和不可恢复提示 | 预览确认后执行；运行任务和最新恢复点不清理 |
| 偏好导出/导入 | 浏览器/本机/当前项目，明确选择范围 | 版本化 JSON，默认仅个人偏好 | 导入先校验、展示差异，再逐范围应用并备份 |
| 恢复默认 | 各自所属范围 | 分组恢复；可提供明确范围的批量恢复 | 不删除文章、草稿、媒体或项目 |
| 闲置自动退出 | 本机策略 | 默认关闭；默认参数 30 分钟，范围 5—240 分钟 | 服务端控制会话，后台轮询不续期 |
| 会话最大有效期 | 本机策略 | 默认关闭；默认参数 24 小时，范围 1—168 小时 | 从登录开始计算，持续操作不续期；修改在下一次请求生效 |

导出不含访问令牌、登录 Cookie、文章正文、草稿、备份文件和 Git 凭据。阶段 7 仅迁移偏好，排除项目路径关联和默认项目标识；依赖默认项目的启动策略在导出中转换为“不自动连接”，默认项目选择通过工作区页面管理。导入不自动连接项目、不修改正文、不执行发布。导入一个范围失败时明确显示成功/失败范围，不伪装成跨浏览器与文件系统的原子事务。

维护列表需要补充稳定的备份元数据。现有裸 `.bak` 文件若缺少项目/原路径映射，标为旧备份；仅在可可靠确认归属时支持恢复，不根据文件名猜测或跨项目写入。清理与恢复互斥，历史状态损坏不影响文章正常读取。

会话策略已替换原令牌 Cookie 机制：登录生成不包含访问令牌的随机会话 ID，服务端在内存中维护其摘要、创建时间和最后有效用户活动。后台轮询、日志刷新不计为用户活动；真实输入、点击、触摸和滚动最多每 30 秒报告一次，同一浏览器的标签页共享会话。超过有效期由 API 拒绝，过期活动不能恢复登录；修改策略在所有现有会话的下一次请求生效，缩短期限可能立即要求重新登录。前端先读取编辑器最新正文并保存完整正文与独立 Frontmatter 的本地恢复副本；禁用草稿、存储失败或其他表单未保存时保留输入，提供重试、下载和明确放弃。退出不终止已启动的预览或发布任务。升级及重启服务需重新登录，旧 Cookie 不被迁入新会话。

## 5. 本地草稿恢复设计

草稿保存在当前浏览器 IndexedDB，与个人设置分开；大段正文不进入 `localStorage`。恢复键包含项目标识、文章 ID 和编辑会话标识，多个标签页各自保留草稿分支，避免静默覆盖。

每条记录包含完整源码、未保存 Frontmatter 行数据、基准文章版本、保存时间、格式和必要的恢复状态。只在真实编辑导致内容变化时保存；临时教程和纯只读查看不生成草稿。原始文本、BOM、换行约定和未知 Frontmatter 数据继续保留。

| 场景 | 行为 |
| --- | --- |
| 同基准版本存在草稿 | 展示时间与摘要，提供恢复到编辑器、丢弃、暂不处理 |
| 磁盘文章版本变化 | 提示冲突，先查看差异；保留当前文件，不自动合并或调用保存 API |
| 保存文章成功 | 更新基准并清除对应已保存草稿；取消旧延迟写入，避免旧草稿重新出现 |
| 保存文章失败 | 保留草稿和未保存状态 |
| 文章重命名 | 按服务端确认的新 ID 迁移记录，避免写入旧目标 |
| 文章删除或项目暂不可读 | 保留恢复副本并标记目标不可用，不自动重建文件 |
| 浏览器额度不足/IndexedDB 不可用 | 显示草稿保存失败，继续手动保存和离开提醒 |
| 用户关闭自动保存 | 停止新增记录，已有记录保留；删除需要明确操作 |

草稿写入使用记录版本和当前编辑代次，处理延迟任务与切换文章的竞态。离开前尽力提交已有待保存内容，但不依赖 `beforeunload` 完成异步持久化；正常输入期间即持续保存。恢复时不重建正在编辑的 Vditor 节点，不把主题或模式设置变化当作正文变更。

## 6. 状态同步与生效约定

- 同一浏览器多个标签页通过 `storage` 事件同步已保存个人偏好；有未保存设置的标签页显示外部修改提醒。
- 项目/本机偏好使用服务端版本；页面进入、项目切换及保存后重新核对。客户端忽略已离开项目的迟到响应。
- 主题与字体更新使用现有 Context 和 CSS 变量，继续保留编辑器实例与运行时类。
- 下次打开生效的默认值不覆盖当前用户临时选择；页内修改模式、大纲或预览路径时，只有明确“记为默认”才写入设置。
- 运行中的任务绑定启动时的配置。预览端口变更不自动杀进程；发布默认值变更不影响已开始的任务。
- 无连接项目、项目只读、状态文件不可写和新版本不兼容各自显示具体状态，不将所有表单统一禁用。

## 7. 验收与交付

每阶段都包含默认值/迁移/校验回归，以及受影响页面的实际浏览器验证。最终覆盖桌面折叠/展开导航、移动端、深浅色、无项目、只读、两个项目、多个标签页和存储失败。

重点验收：

1. 旧主题和项目路径迁移后保持现有行为；恢复默认只影响选择范围。
2. 保存偏好不会修改 Mizuki 文章或站点配置，不会触发发布。
3. 编辑器主题、字体、大纲更新保持光标、正文、原始语法编辑和撤销重做。
4. 草稿恢复保留正文与未保存 Frontmatter；磁盘版本冲突不静默覆盖。
5. 媒体默认值、预览参数和模板按项目隔离，独立内容仓库模式遵守原始源目录契约。
6. 备份恢复、清理和导入有具体范围、版本保护与失败反馈。
7. 会话过期由服务端执行；后台轮询不能阻止闲置退出。

阶段 1—6 已按用户通知完成；阶段 7—8 按新的开始通知推进，详细状态见阶段规划。
