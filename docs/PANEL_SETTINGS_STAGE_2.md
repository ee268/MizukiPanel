# 设置阶段 2：编辑器显示与行为偏好

完成日期：2026-10-09。入口：`/settings?section=editor`。

## 功能与默认值

| 设置 | 默认 | 可选范围 | 生效方式 |
| --- | --- | --- | --- |
| 默认编辑模式 | 按格式自动 | 自动、即时渲染、所见即所得、分屏 | 下次打开文章或重新打开设置预览 |
| 正文字体 | 跟随项目 | 项目、系统、面板内置 | 即时预览 |
| 正文字号 / 行高 | 16px / 1.85 | 12—24px / 1.4—2.4 | 即时预览 |
| 代码字体 | 当前项目等宽字体 | 项目、面板、系统等宽字体 | 即时预览，独立于正文 |
| 代码字号 | 正文字号的 85% | 跟随正文或 10—24px | 即时预览 |
| 制表显示宽度 | 4 字符 | 2、4、8 | 即时预览，不改写原制表符/空格 |
| 默认大纲 / 宽度 | 关闭 / 250px | 开关、180—420px | 即时预览，窄屏收起并限制占比 |
| 拼写检查 | 关闭 | 开关 | 浏览器原生检查，依赖系统/浏览器语言支持 |

自动模式维持现有行为：Markdown 即时渲染，普通 MDX 分屏，内置教程即时渲染。工具栏可临时更改当前模式或大纲，不写入默认偏好。保存默认模式不会重建已打开的编辑器，也不会强制切换当前模式；重新打开设置预览会应用当前预览中的默认模式并保留试写内容。

MDX 的组件和 Mizuki 扩展仍需真实站点预览查看最终效果。显式选择其他原生模式不会增加组件渲染能力；没有恢复以前的独立源码编辑器。

正文字体明确选择系统或面板内置时优先应用该选择；选择跟随项目时保持项目字体模式，若界面已选择系统字体则继续使用系统字体。行内代码沿用正文，反引号补救字体保留；代码块及分屏源码采用独立代码字体/字号。字体与主题更新保留正文、原始语法节点、光标及原生撤销历史。

字体同步检查已覆盖大纲、新建/模板源码预览、Frontmatter、配置行号、日志和预览等待页。默认代码字体跟随项目时也尊重界面的系统字体选择，显式代码字体仍独立；项目代码字体的中文回退采用当前正文字体。详见 [字体同步检查](FONT_SYNC.md)。

设置页的编辑预览可以试写，不生成文章、不调用正文保存 API。仅在文章编辑分类打开时初始化；切换分类或离开会丢弃预览试写内容，设置的未保存修改仍沿用离开确认。

## 存储与结构

浏览器偏好增加 `editor` 分组，保留 schema 1：这是兼容的字段扩展，已有阶段 1 配置读取时补齐默认值，不自动覆盖文件或浏览器原数据。保存保留其他分组和未知扩展字段。

编辑器表单复用阶段 1 的分组保存、取消、恢复本组默认、即时预览、错误保留输入、外部修改提醒和未保存离开保护；跨标签页仍通过 storage 事件和保存前分组基准比对同步。恢复本组默认先修改草稿，不立即保存。

| 模块 | 职责 |
| --- | --- |
| `src/shared/panel-settings/` | editor 类型、默认值和字段校验 |
| `src/client/settings/SettingsCard.tsx` | 外观与编辑器共享保存/冲突卡片 |
| `src/client/settings/EditorSettingsForms.tsx` | 编辑器表单与可试写预览 |
| `src/client/settings/usePersonalDrafts.ts` | 按已登记分组维护草稿及预览 |
| `src/client/articles/editor-preferences.ts` | 按格式默认模式、字体优先级和代码字号 |
| `VditorBodyEditor.tsx` / `vditor-editor.css` | 仅在初始化读取默认模式，原位应用显示与检查 |

本阶段未开发草稿持久化、文章模板、媒体处理、维护或会话功能。本机/项目设置契约和文章保存 API 保持原样。

## 验证

- 新领域测试覆盖按格式/指定默认模式、教程默认模式例外、显式字体与界面字体的优先级、相对/固定代码字号、阶段 1 配置补齐且不写入、未知字段保留、同组旧基准拒绝及所有编辑字段边界。
- 完整测试通过：40 个文件、157 项测试；类型检查、格式检查和客户端/服务端生产构建通过，保留既有的大体积 chunk 提示。
- 真实浏览器验证默认值、每项显示预览与取消、保存/恢复默认、默认模式延后生效、Markdown 与 MDX 显式模式、教程自动即时渲染、Frontmatter 切换、Ctrl+S 与保存按钮读取最新正文。
- 验证跨标签页显示更新不改动正文 DOM、不重建编辑器，光标范围和撤销记录保持；同组冲突保留输入，重新载入可恢复最新值；额度不足保留编辑器设置输入。
- 核对深浅色、移动端无横向溢出，以及链接/加粗/行内代码/代码块/HTML 与 Markdown 图片仍在编辑器中保留。代码中的真实制表符未被设置转换为其他缩进。
