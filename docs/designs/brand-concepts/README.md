# MizukiPanel 标识方案

本目录保存设计草案。“模块窗格”已被选定并应用到页头及网页标签图标；正式资源位于 `static/`，包括转为路径的深浅色 Logo、SVG 图标和 16 / 32 / 48 / 64 / 128 / 256px 多尺寸 ICO。

| 方案 | 构思 | Logo | 网页标签图标 |
| --- | --- | --- | --- |
| 书页折 M | 展开的书页、M 字形与登录卡片的折角 | book-logo.svg | book-favicon.svg |
| 月光面板 | 月弧、面板模块与圆点 | moon-logo.svg | moon-favicon.svg |
| 星笺 | 纸笺折角与镂空星芒，延续灵感元素 | star-logo.svg | star-favicon.svg |
| 流线 M | 连贯的圆角 M，强调创作与流动 | flow-logo.svg | flow-favicon.svg |
| 模块窗格 | 卡片模块组成紧凑的面板标识，强调管理工具 | grid-logo.svg | grid-favicon.svg |
| MP 连字 | 两个首字母共用结构，偏杂志编辑气质 | monogram-logo.svg | monogram-favicon.svg |

各方案使用当前青蓝主色，辅以青蓝及粉紫渐变，并提供单色适配。图标可缩放至 16px / 32px；Logo 字标会在选定方向后进一步校准字距、转换为路径，并输出正式的 SVG / ICO 文件。
