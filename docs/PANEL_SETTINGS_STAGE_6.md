## 预览端口与路径

预览启动读取真实项目对应的设置，Astro CLI 始终使用 `--host 127.0.0.1`、指定端口和 `--strictPort`。端口保存不停止或重启当前进程；状态接口和预览页同时显示实际端口、已保存端口及尚未应用提示。停止后再启动才使用新端口。

已有健康 HTTP 服务继续作为外部服务显示，并明确说明无法确认项目归属；面板不提供停止该外部进程的操作。其他监听服务或不可用 HTTP 服务通过 TCP 占用检查反馈端口冲突，不自动换端口或终止其他进程。Astro 启动时的竞争占用仍由 `--strictPort` 处理，错误保留在运行日志。

状态和日志按项目区分；外部服务不展示面板旧进程日志。工作区切换停止拥有的预览时，继续使用该任务绑定的状态目录，避免读取另一组默认设置。

路径优先级：文章/页面入口的 `path` 参数 → 当前页临时输入 → 首次读取的项目默认路径。轮询和其他位置保存默认值不会覆盖当前路径。项目路径必须以 `/` 开头，允许编码的中文、查询参数和片段；拒绝外部 URL、协议相对地址、控制符、反斜线、无效编码和目录遍历。无效临时输入禁用“新窗口”。保存默认路径不修改文章 URL。

## 日志显示与保留

预览与发布共用日志组件，沿用去 ANSI、按时间/错误/警告/地址高亮及全局字体变量。浏览器偏好设置字号和自动滚动，可通过其他标签页即时同步。检测新尾行而不只检测数组长度，因此达到保留上限后仍能自动滚动；关闭时不会主动改变阅读位置。

保留条数只控制本机内存中的最近日志，不写入新的日志文件，不改变 Git 超时、差异上限或任务执行配置。设置 API 保存后更新有效限制；启动和状态读取也核对本机偏好，后续追加裁剪。页面显示当前有效条数；减少条数不会立即删除已有显示内容，旧条目会在下一次追加后释放。

## 发布默认值

提交表单分为类型、作用域和本次提交说明，并显示组合后的 Conventional Commit。作用域可为空，支持小写字母、数字及 `. _ / -`，最多 80 字符；类型提供常用 Conventional Commit 选项。空说明不能提交，服务端继续执行既有提交标题长度、语法、文件范围和 Git 状态检查。

记忆关闭时每次打开使用基础类型/作用域，说明为空、文件未勾选。开启后从项目偏好填入；刷新状态或任务轮询不覆盖已经编辑的表单。仅在用户明确提交所选文件且提交成功后更新类型/作用域，提交正文和路径不保存；成功后清空当前说明与选择。保存默认值或打开页面不触发提交、推送、同步、构建或还原。

记忆以提交前的发布组为基准，提交后重新核对：其他组变化仍可保存，本组或项目变化则不覆盖新值。相同默认值不重复写入。配置保存失败或遇到未来版本时，接口仍报告 Git 提交成功并附加默认值未保存的说明，客户端明确显示，避免误导用户重复提交。
